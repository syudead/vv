# UI 設計: フォルダの階層で動画を見るフォルダ画面 {#ui-design-folder-screen-for-browsing-videos-by-folder-hierarchy}

**機能**: [親 Issue #145](https://github.com/syudead/vv/issues/145)

出典: 視覚的な規則、シェル、一覧のレイアウトは [ライブラリ UI: 視覚ルールと一覧の構造](../../docs/design-docs/library-ui.md) と [`web/src/index.css`](../../web/src/index.css) の `@theme` に従う。この文書が定めるのは、フォルダ画面がそれらに**加えるもの**（フォルダのカード、パンくずリスト、フォルダのツールバー、状態）だけである。色、角丸、影のトークンは新しく加えない。

## 画面の境界 {#screen-boundary}

- `/folders`（最上位）と `/folders/{rootId}/{segment}…`（各フォルダ）は、ライブラリと同じ `AppShell` の中にある。上部バー、サイドバー、`window` のスクロールはそのまま使う。
- サイドバーの `フォルダ` の項目は `ライブラリ` のすぐ後に置き、lucide の `Folder` アイコンを使う（選択中は、既存の項目と同じく線が太くなる）。`/folders` 以下のどの URL でも選択状態になる（`ライブラリ` はこれまでどおり `/` でだけ選択状態になる）。
- 動画のカードは `web/src/library/VideoCard.tsx` をそのまま使う。フォルダ画面には選択がない（親 Issue の範囲外）ので、カードは**選択のチェックボックスを描かない**形で使う。ライブラリのカードの見た目と振る舞いは変わらない。
- 表（リスト）表示はない。視聴状態の絞り込みと検索欄は #145 の範囲外で、#228 で加えた（[specs/013-library-search/ui-design.md「Folder screen」](../013-library-search/ui-design.md#folder-screen)）。

## ページの構造と階層 {#page-structure-and-hierarchy}

上から下へ、この順に並ぶ。3 と 4 の内容が主で、1 と 2 は従である。

1. **フォルダのツールバー**（上部バーの中）: 並び順とズームだけ。
2. **パンくずリストの帯**（上部バーのすぐ下に貼り付く）: 現在の場所と、階層を上へ戻る道。
3. **子フォルダのグループ**: 見出し `フォルダ N` と、フォルダのカードのグリッド。
4. **動画のグループ**: 見出し `動画 N` と、動画のカードのグリッドと続きの読み込み。

子フォルダがないときは 3 を見出しごと省き、直下の動画がないときは 4 を見出しごと省く。「0」と書く見出しはない。最上位（`/folders`）には 3 だけがあり、見出しは `メディアフォルダ N` である。

ページには現在のフォルダ名（最上位では `フォルダ`）を持つ、見た目では隠した `h1` がある。利用者が別のフォルダへ移ると（プレーヤーから戻るときを除く）、フォーカスは `h1` へ移り、ページは先頭までスクロールする。これでスクリーンリーダーの利用者は、移ったことと今いる場所を知る。

## 余白と密度 {#spacing-and-density}

- ページの外側の余白と要素の間隔は `LibraryPage` と同じである（横は `px-3` / `sm:px-4`、要素の間の縦は `gap-3`、下端は `pb-24`）。
- グリッドはライブラリと同じ構造である（中央寄せで折り返し、カードの間は `gap-2.5`、カード幅は `min(var(--card), 100%)` で、`--card` はズームの `--spacing-card-0..3`）。**フォルダのカードと動画のカードは同じ幅**なので、同じズームでは同じ列数になる。
- グループの間（3 と 4 の間）は `mt-6` 程度で、カードの間の `gap-2.5` よりはっきり広い。
- 見出しはグリッドの左端ではなくページの左端にそろえ、見出しとグリッドの間は `gap-2` である。

## フォルダのカード {#folder-card}

フォルダのカードは動画のカードと同じ箱（`rounded-lg`、`bg-surface`、`shadow-card`。ホバーで `-translate-y-0.5` と `shadow-card-hover`）を使い、**上半分の絵だけ**を変える。動画のカードの上半分は端まで届く平らなサムネイルだが、フォルダのカードは箱の中に**タブ付きのフォルダの輪郭**を描き、そこへサムネイルを差し込む。輪郭が違うので、利用者は 2 種類をひと目で見分けられる。

上半分（`aspect-video`）は、奥から手前へ次の層を持つ。

1. **奥の板**: 箱から内側に下げた `rounded-md` の `bg-elevated` の面。左上に同じ色のタブ（板の幅の約 2/5、高さ `h-3`、上の角だけ丸い）がある。
2. **差し込んだサムネイル**: 1〜4 枚の `previews` を、フォルダに差し込んだ紙のように横に少しずつずらして重ねる。各画像は板の幅の約 70%、16:9、`rounded-sm` で、縁は `border-border-strong`、影は `shadow-card` である。枚数に応じて左右に均等に広がる。左から数えて奇数番目はやや高い位置にあり、それぞれ左右どちらかに数度傾く（1 枚のときは中央に置き、傾けない）。重なりは板の縦の中央に置き、何にも覆われない。画像は `object-contain` を使う（縦長の動画は切り取らずに全体を示す）。代替テキストは空で、読み上げない。
3. **手前に出すプレビュー（ホバー）**: マウスが輪郭の上を横に動くと、ポインターの位置（幅を枚数で等分する）に当たる 1 枚がまっすぐになり、1.12 倍に拡大して板の中央の手前に出る（影は `shadow-card-hover`）。ポインターが離れると、元の位置と傾きに戻る。動きは 200ms かかり、動きの抑制のもとでは切り替わるだけである。マウス以外のポインターでは画像を手前に出さない（タップでフォルダを開く）。
4. **プレビューの再生**: 手前の画像に `previewUrl` がある（一覧用のプレビューが生成済みで配信できる）とき、手前に出てから 400ms 後に、動画のカードのホバープレビューと同じ一覧用のプレビュー動画を、その 1 枚の枠の中で消音でループ再生する。再生が始まるまではサムネイルのままである。別の画像へ移ると、その画像の動画に切り替わる。ポインターが離れると再生は止まり、読み込みを解放する。`previewUrl` のない画像（未生成、失敗、ファイルがない）と、読み込みに失敗した画像は、サムネイルとして手前に出るだけである。

`previews` が 0 枚のときは、奥の板とタブだけを描く。空の枠、壊れた画像、「画像なし」の文字は出ない（受け入れ条件 6）。

下半分は動画のカードと同じ余白（`px-3 pt-2 pb-3`、行の間は `gap-1`）で、次を持つ。

- **フォルダ名**: 動画のタイトルと同じ `text-sm font-medium text-fg` で、2 行で省略する（`line-clamp-2 break-all`）。`title` 属性が名前全体を持つ。
- **件数**: `動画 N 本 · フォルダ M 件` を `text-xs text-fg-muted tabular-nums` で示す。0 のときも示す（受け入れ条件 4 と 6 がこの文言を確かめる）。
- **パス**（最上位のカードだけ）: `rootPath` を `text-xs text-fg-muted` の 1 行で示す。収まらないときは**先頭**を省略する（`…/a/movies`）。同じ名前の登録フォルダを見分けるのはパスの末尾だからである（受け入れ条件 2）。`title` 属性がパス全体を持つ。

カード全体が 1 つのリンクで、アクセシブルな名前は `{名前}、動画 N 本、フォルダ M 件` である（最上位では後に `、{パス}` が続く）。フォーカスは、リンクにキーボードのフォーカスがあるときだけ、全体の `:focus-visible` と同じ `link` の色と太さの外側の輪郭として、箱の外側に（角丸に沿って）示す。箱は `overflow-hidden` なので、リンク自身の輪郭は切り取られて見えなくなる。装飾的な動き（ホバーでの浮き上がりと影の遷移）は `motion-reduce:` のもとで止まり、最終的な影の状態は残る。

## パンくずリストのバー {#breadcrumb-bar}

- `sticky`（`top-navbar`）で上部バーのすぐ下に固定し、スクロール中も残る（親 Issue `操作の優先順位`）。面は上部バーと同じ `bg-bg/90` と `backdrop-blur-md`（下をスクロールするグリッドがうっすら透ける）で、下端は `border-border` である。高さは 1 行で、上部バーより低い（`h-10` 程度）。横の余白はページに合わせる。
- `nav`（`aria-label="パンくず"`）の中の `ol` である。各段は `フォルダ › registered folder name › … › current folder` である。区切りは lucide の `ChevronRight`（`text-fg-subtle`、`aria-hidden`）である。
- 文字は `text-xs` である。祖先の段は `text-fg-muted` のリンクで、ホバーで `text-fg` と `bg-hover-wash` になる。現在の場所はリンクではない `text-fg font-medium` の文字で、`aria-current="page"` を持つ。
- 各段は 1 行で、長い名前は末尾を省略する（祖先は決めた最大幅まで、現在の場所は残りの幅を使う）。`title` 属性が名前全体を持つ。帯そのものは折り返さない。
- `md` 未満で段が 4 つ以上あるときは、**先頭**を畳み、`… › parent › current` だけを示す（親 Issue `幅による出し分け`）。`…` は操作できず、読み上げない。隠れた段へは親を 1 段ずつたどって届き、最上位へはサイドバーの `フォルダ` からいつでも届く。この切り替えは CSS の幅のブレークポイントだけを使う（library-ui.md 4）。
- 最上位（`/folders`）には `フォルダ` の 1 段だけがあり、それが現在の場所である。

## ツールバー {#toolbar}

> **この節は #228 で置き換えた（[specs/013-library-search/ui-design.md「Folder screen」と「Toolbar」](../013-library-search/ui-design.md#folder-screen)）。** フォルダ画面のツールバーは今では検索欄を先頭にした中央寄せのレイアウトを使い、検索欄、絞り込み、並び順（7 つの並び順、向き、ランダム用の Shuffle）を持つ。以下の「検索欄がないので」右寄せにするという記述は #228 より前の状態を示し、もう実装と合わない。

上部バーの中（`TopBarPortal`）には、ライブラリのツールバーと同じコンポーネントと同じ幅のブレークポイントで、**並び順とズームだけ**を置く。検索欄がないので、操作は右寄せにし、右端の上部バーの更新の隣にまとめる（中央に操作が 1 つだけ浮くのを避け、内容より控えめにするため）。

| 幅 | 操作 |
| --- | --- |
| `md` 以上 | 並び順のメニューボタン（`追加日`、`題名`） |
| `xl` 以上 | ズームのスライダー |
| それより狭い幅 | 1 つの「表示と並び順」ボタン（`表示と並び順`）が並び順とズームをまとめて開く |
| 最上位（`/folders`） | ズームだけ。動画を示さないので並び順はない |

並び順を変えると動画のグループだけを読み込み直す。子フォルダのグループは描き直さず、並べ替えもしない（受け入れ条件 8）。並び順とズームはライブラリと同じ保存値を読み書きする（要件 13）。

## 状態 {#states}

| 状態 | 画面が示すもの |
| --- | --- |
| 最上位の読み込み中 | `メディアフォルダ` の見出しと、6 つのフォルダのカードのスケルトン（輪郭の形の `Skeleton`） |
| 登録フォルダが 0 件 | ライブラリの空の状態と同じコンポーネントで `メディアフォルダが登録されていません` を示す。操作は `設定を開く`（`/settings` へのリンク） |
| フォルダの読み込み中 | パンくずリストはまず URL から分かる段を示し、名前が必要な登録フォルダの段だけをスケルトンにする。内容は 3 つのフォルダのカードのスケルトンと 6 つの動画のカードのスケルトン |
| 登録フォルダが空（取り込み前） | 空の状態のコンポーネントで `このフォルダにはまだ動画がありません` と `取り込むと、ここに並びます。` を示す。操作は既存の `取り込む` |
| フォルダが見つからない（404） | 空の状態のコンポーネント（`FolderX` アイコン）で `このフォルダは見つかりません` と `登録が外れたか、中の動画が無くなりました。` を示す。操作は `フォルダの一覧へ`（`/folders` へのリンク）。空のグリッドは出さない。登録フォルダの名前が分からないので、パンくずリストは `フォルダ › name of the segment being opened` だけである（解釈できない URL では `フォルダ › …`） |
| 読み込みの失敗（404 以外） | ライブラリと同じ `LoadFailed`（再試行） |
| 続きの読み込み中、または続きの読み込みの失敗 | ライブラリと同じ（6 つのスケルトン。失敗時はグリッドの下に `続きを取得できません` と再試行） |
| 再生できない動画、またはサムネイルのない動画 | 動画のカードの既存の表示 |

## アクセシビリティ {#accessibility}

- フォルダのカードはリンクである。アクセシブルな名前は前述の形で、プレビュー画像は代替テキストが空で読み上げない。
- パンくずリストは `nav` > `ol` で、現在の場所に `aria-current="page"` がある。区切りと `…` は読み上げない。
- 見出し `フォルダ N` と `動画 N` は `h2` である。件数は見出しの一部として読み上げる。
- キーボード: Tab の順は DOM の順で、本体はシェルの既存の順の後に来る。本体の中では、どの幅でも順はパンくずリスト → 子フォルダのカード → 動画のカードである。フォルダのツールバーは上部バーの中（`TopBarPortal`）にあるので、ライブラリと同じく本体より前に来る。シェルの部分はサイドバーの状態による。

  | サイドバーの状態 | Tab の順 |
  | --- | --- |
  | レール（640px 以上） | ロゴ → フォルダのツールバー（並び順 → ズーム、狭い幅では 1 つの `表示と並び順` ボタン） → 更新 → サイドバーの項目 → 本体 |
  | 閉じたドロワー（640px 未満の初期状態） | サイドバーは `inert` で Tab の順に入らない。☰ → フォルダのツールバー → 更新 → 本体 |
  | 開いたドロワー（☰ で開いた） | 更新 → `メニューを閉じる` → サイドバーの項目 → 本体 |

  Enter でフォルダを開くか動画を再生する。戻るにはパンくずリスト（Shift+Tab）かブラウザの戻るを使う。
- 加えた文字と面の組は、`bg`、`surface`、`elevated` の上の既存の `fg` と `fg-muted` で、`tokens.test.ts` の組にすでにある。新しい組は加えない。
