# 一時的な SDD 成果物 {#temporary-sdd-artifacts}

進行中の SDD 機能は、その Plan と補助する成果物を feature ブランチ上のここに置く。要件は親 GitHub Issue が管理する。これらのファイルはその機能のための作業用の入力であり、後の実装や調査の参照先ではない。

統合前に、残すべき決定を `docs/design-docs/` に記録し、永続的な参照先を更新し、検証後に機能のディレクトリとその日本語訳を削除する。Git の履歴には途中の作業が残る。成果物全体を設計文書やリポジトリのアーカイブへ移してはならない。

現在のシステムは設計文書、コード、API スキーマ、テストで説明される。永続的な文書とコードは、ここにある機能のディレクトリを決して引用しない。
