# クイックスタート: 実際の写真をアップロードし、実際の ComfyUI で編集する {#quickstart-upload-a-real-photo-and-edit-it-with-a-real-comfyui}

この手順は、実際の端末の写真がサムネイルになること、そして実際のモデルがアップロードした写真と生成したサムネイルを編集することを実証する。`task check` と `task test-e2e` は生成した画像をアップロードし、偽の ComfyUI を動かすので、カメラの JPEG の特徴やモデルの出力を捉えられない。

## 前提条件 {#prerequisites}

- feature ブランチから実行し ([development.md](../../docs/how-to/development.md))、所有者としてログインし、ライブラリの動画を 1 つと、Settings のテストに通る ComfyUI の接続を持つ vv ([045 クイックスタート](../045-comfyui-thumbnails/quickstart.md))。
- スマートフォンかカメラで最大の解像度で撮った写真 (48 または 108 メガピクセルのモードがあればそれ)、縦長の写真、任意の大きさの PNG と WebP、120 メガピクセルを超える画像を 1 つ (つなぎ合わせたパノラマ、またはスキャン)。

## 手順 {#steps}

| 手順 | 期待する結果 | 受け入れ条件 |
| --- | --- | --- |
| 動画のページ: PNG、次に WebP、次にスマートフォンの写真をアップロードする | それぞれが数秒のうちに、ライブラリのカード、動画のページ、別の動画の関連動画でサムネイルになる | 1, 2 |
| 再読み込みする。完全なスキャンを始める | 写真が残る | 1 |
| 縦長の写真を横長の動画にアップロードする | カードとページは、写真の中央を動画の形で、帯なしで示す | 3 |
| 120 メガピクセルを超える画像をアップロードする | 画像が大きすぎると伝える失敗の行。サムネイルは変わらない | エッジケース |
| 別のブラウザーでのゲストのセッション | アップロードの入口がなく、編集するときに元の選択がない | 7 |
| 今のサムネイルから編集を始める。写真の中の 1 つの物体を塗る。実行する。適用する | エディターは写真を元として示す。結果は塗った範囲の外で写真を保つ。サムネイルは結果になる | 5, 6 |
| もう一度今のサムネイルから編集を始める | 生成した画像が元になり、実行の後に新しい結果の隣に示される | 5 |
| 「Use the frame instead」 | サムネイルは再びフレームになる | 4 |
| 写真をもう一度アップロードし、それから「use current frame as thumbnail」 | サムネイルはそのフレームになる | 4 |
