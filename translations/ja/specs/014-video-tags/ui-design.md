# UI 設計: 動画のタグとタグでの絞り込み {#ui-design-video-tags-and-tag-filtering}

**機能**: [親 Issue #193](https://github.com/syudead/vv/issues/193)

出典: 視覚的な規則、シェル、一覧の密度は [ライブラリ UI: 視覚ルールと一覧の構造](../../docs/design-docs/library-ui.md) と [`web/src/index.css`](../../web/src/index.css) の `@theme` に従う。動画ページの構造は [012 の ui-design.md](../012-video-detail-ia/ui-design.md) に従い、ツールバー、一致なしの状態、`条件を解除` は [013 の ui-design.md](../013-library-search/ui-design.md) に従う。URL の形と履歴は [contracts/list-url.md](contracts/list-url.md) で、エラーの `code` と件数は [contracts/tags-api.md](contracts/tags-api.md) で決めてあり、この文書はそれらを見直さない。この文書が定めるのは、カードのタグの行、絞り込み中のタグ、動画ページのタグ、選択バーのタグの操作、タグ管理ページが既存の画面に**加えるもの、または変えるもの**だけである。色、角丸、影のトークンは新しく加えない。

## 画面の境界 {#screen-boundary}

| 場所 | この機能が加えるもの |
| --- | --- |
| ライブラリ (`/`) のグリッドのカード | タイトルの下のタグの行。ライブラリのリスト表示の行にはタグの行がない。フォルダ画面のカードにも同じタグの行がある。タグを押すと、そのタグで絞り込んだライブラリ (`/?tag=<id>`) へ移る |
| ライブラリ本体の上端 | タグで絞り込んでいる間だけ、要約の行の上に絞り込み中のタグの行。ツールバー (トップバーの中) には何も加えない |
| 動画ページ (`/videos/:id`) | タイトルの下のタグの一覧 |
| 選択バー | タグの一括追加と一括解除の操作。配置は [library-ui.md、一覧のレイアウト](../../docs/design-docs/library-ui.md#list-layout) に従う |
| タグ管理ページ (`/tags`) | `AppShell` の中。サイドバーの `フォルダ` のすぐ後に `タグ` の項目 (lucide `Tags`) がある |

## タグのチップ {#tag-chip}

タグは役割の違う 3 つの形で現れる。どれも 1 つの見た目の骨格 (`h-5` または `h-6`、`rounded-sm`、`px-1.5` から `px-2`、`text-xs`、省略付きの 1 行) を共有し、色と印で見分ける。

| 形 | 場所 | 面と文字 | 印 | 押したとき |
| --- | --- | --- | --- | --- |
| 動画のタグ | カード、動画ページ | `bg-elevated`、`text-fg-muted` (動画ページでは `text-fg`) | なし | そのタグで絞り込む |
| 絞り込み中のタグ | 一覧の上 | `bg-accent-soft`、`text-link` (現在の `Chip` のアクセント) | 先頭に lucide `Tag`、末尾に `X` | その絞り込みを外す |
| 候補、集計 | 候補の一覧、選択バー | 行の形 (後述の「コンボボックス」) | 一部にだけ付くときの文言 | 付ける、または外す |

- 長い名前はチップの文字の `min-w-0 truncate` で末尾を省略し、`title` に完全な名前を入れる。チップの最大幅は行の幅 (`max-w-full`) なので、100 文字の名前でも 360px で横にはみ出さない。
- アクセントの色が付くのは絞り込み中のタグだけである。動画のタグは中立のままなので、どのタグで一覧を絞り込んでいるかは色でも分かる。色だけが手がかりではない。絞り込み中のタグには `Tag` のアイコンと行の先頭の文言 (後述の「絞り込み中のタグ」) もある (`UI品質`「アクセシビリティ」)。

## ライブラリのカード {#library-card}

### タグの行 {#tag-row}

- タイトル `h3` のすぐ下、今メタデータの行がある場所に 1 行置く。タイトルとの間隔は今の `gap-1`、下の余白は今の `pb-3` のままにする (`UI品質`「余白のリズム」)。
- 行は `flex flex-nowrap gap-1 overflow-hidden` である。チップは `gap-1` で等間隔に、API の順 (名前の自然な順) に並ぶ。
- 行もカードの `article` も中身を切り取るので、共通の `:focus-visible` の外側の輪郭はチップの外で切れてしまう。カードのチップ (と `+N`) だけは輪郭をチップの内側に描く (`focus-visible:outline-offset-[-2px]`)。色と太さは共通のままにする。
- チップは `h-5`、`text-xs` で、タイトル (`text-sm font-medium`) より小さく `text-fg-muted` なので、タイトルより先に目を引かない。視聴済みのカードではタイトルも `text-fg-muted` だが、大きさとチップの面で見分けられる。
- タグのない動画には行がない。「タグなし」の文言も置かない。空の行は分類がないことを空白で伝えることになり、何も伝わらない。グリッドの各行のカードは今と同じく高さがそろう (`flex-wrap` の既定の `stretch`)。
- 行はカードの下端に置くので、タイトルが 1 行でも 2 行でも、グリッドの行の中でタグの行がそろう。そのために行ではなくカードのリンクが `flex-1` で伸び、タイトルと行の間の空きはリンクの領域 (押すと開く、または選ぶ) に属する。

### あふれ {#overflow}

- 1 行に収まらないタグは行の末尾の `+N` チップに置き換え、収まるチップだけを示す (`UI品質`「情報の密度」)。`+N` は動画のタグの形で、文字は `tabular-nums` である。フェードアウトは採用しない。名前が切れたのか、ほかにもタグがあるのかが分からないからである。
- `+N` はボタンである。隠れたタグを同じチップとして並べた `ui/Popover` を開く。チップを押すと、カードの行と同じくそのタグで絞り込み、ポップオーバーを閉じる。アクセシブルな名前は `ほかのタグ N 個を表示` である。一覧がどう開き、チップをどう並べ、どうビューポートの中に収まり、長い名前をどう示すかは [041 UI 設計、一覧](../041-tag-overflow-list/ui-design.md#the-list) で定める。
- 何個のチップが収まるかは、描画した後に行とチップの幅を測って決める。CSS だけでは個数を出せない。library-ui.md の [幅のブレークポイントは CSS に置き、サイドバーは例外とする](../../docs/design-docs/library-ui.md#width-breakpoints-in-css-and-the-sidebar-exception) が避けるのは JavaScript で画面の幅によって分岐することで、中身が収まるかを測ることとは違う。測る前の 1 フレームだけ行が伸び縮みしないよう、個数は描画の前 (レイアウトエフェクト) に決め、カードの大きさか画面の幅が変わったときに測り直す。一覧は仮想スクロールを使わない (library-ui.md、[仮想スクロールは使わない](../../docs/design-docs/library-ui.md#no-virtual-scrolling)) ので、読み込んだすべてのカードの行を監視する。カードごとに 1 つのオブザーバーではなく、一覧の 1 つの `ResizeObserver` がすべての行を見る。カードの幅はズームの段階ごとに一定なので、測り直すのはズームの段階か画面の幅が変わったとき、またはタグが変わったときだけである。

### カードの構造と押す操作 {#card-structure-and-pressing}

- 今はカード全体が動画ページへの 1 つのリンクである。タグの行はリンクの**外**、タイトルの下の同じ `article` の中に置く (リンクの中に操作できる要素を入れ子にしない)。区切り線はなく、見た目は 1 枚のカードのままである。
- カードのホバーでの浮き上がり、影、ホバーのプレビューは、今と同じくタグの行の上でも働く。
- タグのチップはどれもボタンである。押すと今の条件にそのタグを加え ([list-url.md、タグを加える、外す](contracts/list-url.md#adding-and-removing-a-tag))、動画ページへは移らない。すでに絞り込み中のタグを押しても何も変わらず、そのチップはほかと同じ見た目である (絞り込み中の印は一覧の上にだけ出る)。
- 16 個が絞り込み中のときに 17 個目のタグを押しても加えず、トーストで `絞り込めるタグは 16 個までです` と伝える。
- **選択中** (1 件以上を選んでいる) は、タグのチップをボタンとして描かない。文字と面は残り、押すとカードの選択が切り替わる (Edge Case `選択中にタグを押したとき`)。Tab の順からも外れる。選択中にタグの名前と「絞り込む」を読み上げると、押したときの動作と食い違う。`+N` も操作できなくなる。
- カードの中のキーボードの順: チェックボックス → リンク (タイトル) → タグ → `+N`。

## 絞り込み中のタグ {#active-tag-filters}

- ライブラリ本体の上端、要約の行の上の 1 行で、タグで絞り込んでいる間だけ示す。タグで絞り込んでいないときは場所を取らない。
- 行は要約の行と同じく中央にそろえる (`flex flex-wrap justify-center items-center gap-1.5`)。`text-xs text-fg-muted` の文言 `タグで絞り込み中` で始まり、続いて絞り込み中のタグを名前の自然な順に並べ、収まらないときは折り返す。
- 各チップは `Tag` のアイコン、名前、`X` のアイコンを持つ 1 つのボタンで、どこを押してもそのタグだけを外す (`UI品質` `ワンクリックで届き`)。× だけを小さな的にする案は採用しない。チップ全体の操作は 1 つなので、的を小さくする理由がない。ホバーで内側に `ring-1 ring-inset ring-border-strong` の縁が出る (動画のタグのチップと同じ)。文字の色を変える案は採用しない。`accent-hover` と `link` は同じ値なので、見た目が何も変わらない。
- 外した後、フォーカスは次のチップへ、なければ前のチップへ移り、最後の 1 つだったときは検索ボックスへ移る。外したチップは消え、フォーカス先も一緒に消えてしまうからである (013 の一致なしの状態と同じ)。
- 階層: 行はツールバーの下の本体にあり、ツールバーの部品より小さい (`h-6`、`text-xs`)。グリッドより先に目を引くアクセントの面はこれだけなので、今の条件が一目で読める。
- タグの一覧を読み込むまでは、URL の `id` ごとに 1 つ、各チップに名前の代わりに `Skeleton` (`w-12`) を置き、読み込んだら名前に置き換える。
- 絞り込みメニューの `条件を解除` (013「絞り込みメニュー」) はタグで絞り込んでいる間も現れ、押すとタグの絞り込みも外す。タグは絞り込みボタンの数に数えない ([list-url.md、タグを加える、外す](contracts/list-url.md#adding-and-removing-a-tag))。
- 要約の行は形式を変えず、タグの名前を含めない。件数は `tag` を含めた `total` である。
- 一致なしの状態 (013「一致なしの状態」) は、013 の現在の契約 (PR #262) のとおり、検索語、絞り込み、検索範囲のチップや注記を持たず、`条件を解除` ボタンも持たない。タグの絞り込みも同じに扱い、一致なしの状態の中にチップや外す操作を加えない。絞り込み中のタグが見えるのは一致なしの状態の上にあるこの行だけで、外すのはここか、絞り込みメニューの `条件を解除` (タグも含めすべてを外す) である。
- 検索語、視聴状態、再生できるか、タグを変えると選択を解除する。条件の違う一覧で選んだ動画が、隠れたまま選ばれ続けないようにするためである。

## 動画ページのタグ {#video-page-tags}

### 配置 {#placement}

- タイトル (`h1`) のすぐ下。タグは動画を分類するもので、タイトルと一緒に読まれる。カードでもタイトルのすぐ下に示すので、一覧から開いたときも順が同じになる。
- タイトルとタグの一覧で 1 つのグループ (`flex flex-col gap-2`) を作り、グループと区切り線の間隔は今の `gap-5` とする。タイトルとタグの間を `gap-5` にすると、タグが属性の側に属するように見える。
- 012 の「タイトルの下にチップやボタンを置かない」(視覚レビューの基準、「情報の密度」) は、この機能がタグの一覧についてだけ改める。要約の行、ボタン、ほかのチップはタイトルの下に置かないままである。
- 階層は小さなチップ (`h-6`、`text-xs`) と中立の面で保ち、タイトル (`text-xl` から `text-2xl`、`font-semibold`) より先に目を引かない (`UI品質`「視覚的な階層」)。
- ラベル (`TAGS` など) は置かない。チップの形でタグだと分かり、タイトルのすぐ下のラベルの行は画面を散らかす。グループの見出しは視覚的に隠した `h2` `タグ` である。
- 一覧は `flex flex-wrap items-center gap-1.5` である。付いたタグのチップの後、同じ行に `タグを追加` の入力欄を置く。行は折り返す。

### チップ {#chip}

- `h-6`、`text-xs`、`bg-elevated`、`text-fg`。名前の部分 (リンク) と × の部分 (ボタン) に分け、その間に `bg-border-strong` の縦線 (`w-px h-3.5`) を置く。

| 部分 | 要素 | 押したとき | アクセシブルな名前 |
| --- | --- | --- | --- |
| 名前 | `/?tag=<id>` への `Link`。移動するのでボタンではなくリンクにし、新しいタブでも開ける (管理ページの名前と同じ) | この 1 つのタグで絞り込んだライブラリの一覧を開く | `〈名〉で絞り込む` |
| × | `size-6` の正方形、lucide `X` (`size-3`) | この動画からタグを外す | `〈名〉をこの動画から外す`。絞り込み中のタグの `〈名〉の絞り込みを外す` とは文言で区別する (`UI品質`「アクセシビリティ」) |

- 外した後、フォーカスは次のチップの × へ、なければ前のチップの × へ移り、最後の 1 つだったときは `タグを追加` の入力欄へ移る。
- チップはサーバーが応答してから加える、または外す。待つ間、その × は `disabled` になり、入力欄は「コンボボックス」で述べる送信中の状態になる。

### 追加の入力欄 {#add-input}

- コンポーネントは後述の「コンボボックス」である。入力欄は `h-6`、`w-40`、`bg-field`、`border-border`、`rounded-sm`、`text-xs` で、左に lucide `Plus` (`size-3`、`text-fg-muted`) を置き、プレースホルダーは `タグを追加` である。フォーカスすると `border-accent` になる (検索ボックスと同じ)。
- 確定すると入力欄は空になってフォーカスを保つので、すぐに次のタグを加えられる。新しいチップは名前の順の位置に入る。
- 入力欄にフォーカスがある間は、動画ページのキー (Space、←→、F、M、0、Esc) は働かない (`keyboard.ts` の今の `isEditable`)。Esc は候補の一覧が開いていれば閉じ、そうでなければ入力欄を空にする。空の入力欄での Esc は何もしない。ページを閉じるのは入力欄の外で押した Esc だけである。

### 状態 {#states}

| 状態 | 画面が示すもの |
| --- | --- |
| 詳細の読み込み中 | タグの一覧はない (タイトルと同じくスケルトンの中) |
| タグなし | タイトルの下に `タグを追加` の入力欄だけ |
| 付ける、または外すのに失敗 | 一覧のすぐ下に `text-xs text-danger` の 1 行 (`role="alert"`): `タグを付けられませんでした` または `タグを外せませんでした`。入力欄の文字は残り、Enter で再試行する。次の操作で消える |
| タグがもう無い (`tag_not_found`) | トースト `タグ「〈名〉」はもう無いため、一覧を取り直しました`。タグの一覧とこの動画を取り直す |

## コンボボックス {#combobox}

動画ページの `タグを追加`、選択バーの `タグを付ける` と `タグを外す`、管理ページの統合先の選択は、1 つのコンポーネント (`web/src/ui/Combobox.tsx`) を使う。ARIA 1.2 のコンボボックス (入力欄 + リストボックス、`aria-activedescendant`) である。

- 候補の一覧は入力欄の下 (選択バーでは上) に、`ui/Popover` と同じ面 (`bg-elevated`、`shadow-elevated`、`rounded-md`) で現れる。幅は `w-64` で、8 行を超えるとスクロールする。フォーカスで開き、入力欄が空のときはすべての候補を示す。
- 候補の行は `h-8`、`px-2.5`、`text-sm` である。名前は `text-fg` で 1 行に省略し、右に補足の情報を `text-xs text-fg-muted tabular-nums` で置く (管理ページと同じく件数。選択バーの外す候補では後述の「一部」の印)。アクティブな行は `bg-hover-wash` である (メニューの項目と同じ)。
- 絞り込み: 名前かシノニムに入力を含むタグを、大文字と小文字を区別せずに残す (管理ページの検索と同じ)。前方一致を先に、次に名前の自然な順に並べる。シノニムで一致したタグは、名前の下に `text-xs text-fg-muted` で `シノニム: アニメ` を示す。示す名前は常に元の名前である (要件 7)。
- `タグを追加` では、その動画にすでに付いているタグを候補にしない。
- 入力の綴りと完全に一致する名前もシノニムもないとき、一覧の末尾に `「〈入力〉」を作成` の行 (lucide `Plus`) を置く。`Anime` があるとき、`anime` と入力するとこの行が出る (要件 4)。完全に一致するものがあるときは出ない。

キー:

| キー | 動作 |
| --- | --- |
| ↓、↑ | 行の間を移る。端で止まる |
| Enter、アクティブな行がある | その行を確定する |
| Enter、アクティブな行がない | 入力の綴り (前後の空白を除く) を確定する。名前かシノニムが一致するタグ、なければ新しいタグである。作成の行を持たない形 (選択バーの `タグを外す`、統合先) は、綴りが候補の名前かシノニムと完全に一致するときだけ確定し、そうでなければ何もしない |
| Tab | 確定せずに一覧を閉じて次へ移る |
| Esc | 一覧が開いていれば一覧だけを閉じる。ポップオーバーやダイアログの中のコンボボックスでは、一覧が閉じていればそのポップオーバーやダイアログだけを閉じる。どちらの場合も Esc はそこで止まり、外側 (選択の解除、動画ページを閉じる操作) には届かない。動画ページの入力欄での Esc は、前述の「追加の入力欄」のとおりに働く |

- 名前の検証 (要件 4): 入力のたびに確かめる。その名前で作れないときは、入力欄の下の `text-xs text-danger` の 1 行が理由を示し、Enter を受け付けない。理由は `改行やタブは使えません` と `100 文字以内にしてください（今 101 文字）` である。空または空白だけの入力は、入力中には理由を示さない (確定の後や開いたときの空の入力欄は普通の状態である)。その状態で Enter を押したときだけ `名前を入力してください` を示す。文字数は、サーバーと合わせて ([data-model.md、名前の規則](data-model.md#name-rules))、前後の空白を除いた名前のコードポイントで数え、JavaScript の `length` (UTF-16 の単位) では数えない。入力欄には `maxLength` を付けない。付けると 101 文字目を黙って捨て、理由を示す手段がない。入力欄の `aria-describedby` は理由の行を指す。
- 改行は入力欄の値からは見つけられない。1 行の `input` は値に入る前に改行 (LF、CR) を取り除くので、`旅行\n2024` を貼り付けると `旅行2024` になり、別の名前を確定してしまう。そのため元の文字列を、貼り付け (`paste` の `clipboardData`) とドロップ (`beforeinput` の `insertFromDrop`) の時点で確かめる。改行を含むときは入力を受け入れず (`preventDefault`)、値はそのままにし、理由 `改行やタブは使えません` を示す。理由は入力が次に変わるまで残り、それまでは Enter も確定のボタン (`作成`、`追加` など) も受け付けない。入力欄にはまだ貼り付け前の名前があり、確定すると、利用者が貼り付けた名前ではなくその名前を確定してしまうからである。入力が変わると理由は消え、新しい値が上の検証を通ってから確定を受け付ける。改行のない部分だけを受け入れる案は採用しない。貼り付けたものと違う名前が黙って入力欄に入ってしまう。タブやほかの制御文字は値に残り、入力ごとの検証で捕まえる。この扱いは、タグの名前を入力するすべての入力欄 (「コンボボックス」、管理ページの作成、改名、シノニムの追加) で同じである。
- 送信中、入力欄は `aria-busy="true"` を持ち、Enter を受け付けない。入力欄の右端に `LoaderCircle` (`size-3`、`animate-spin`) を示す。

## 選択バー {#selection-bar}

2 つのタグの操作は 1 つのメニューにまとめない。狭い幅では手順が 1 つ増えるからである。

### 付ける {#add}

- 押すと、バーの上に「コンボボックス」を入れた `ui/Popover` を開く (今の `PopoverContent` は向きを受け取らないので、上に開くための `side` プロパティを加える)。フォーカスは入力欄へ移る。候補はすべてのタグで、それぞれの右に件数を置く。確定すると選んだすべての動画にタグを付け、ポップオーバーを閉じ、トーストで `N 件に「〈名〉」を付けました` と伝える。フォーカスは `タグを付ける` へ戻る。
- 付けた後も選択は残るので、続けてほかのタグを付けたり外したりできる。

### 外す {#remove}

- 押すと同じ種類のポップオーバーを開き、選んだ動画のタグの集計を取得する。届くまで、ポップオーバーは `読み込み中…` (`text-xs text-fg-muted`、`role="status"`) を示す。
- 中身は作成の行のない「コンボボックス」で、候補は集計にあるタグだけである。各行の右に、すべての動画に付いたタグは `3 件` を、一部にだけ付いたタグは lucide `CircleDashed` (`size-3`) と `一部 1 / 3 件` を示す (要件 2)。色は変えない。`一部` という語とアイコンで見分け、行のアクセシブルな名前は `一部の動画だけ、3 件中 1 件` を含む。
- 確定すると選んだすべての動画からタグを外し、トーストで `N 件から「〈名〉」を外しました` と伝える。
- 選んだ動画のどれにもタグがないとき、ポップオーバーは `選んだ動画にタグはありません` を示す。
- 集計を取得できないとき、ポップオーバーは `text-xs text-danger` の 1 行 (`role="alert"`) `タグを取得できませんでした` と、ghost の `sm` の `Button` `再試行` を示す。選択は残る。

### 失敗 {#failure}

- 失敗したとき、ポップオーバーは開いたままで、入力欄の下に `text-xs text-danger` の 1 行 (`role="alert"`) を示す: `付けられませんでした。もう一度お試しください` または `外せませんでした。もう一度お試しください`。選択と入力欄の文字は残り、Enter で再試行する (Edge Case `一括操作の途中失敗`)。
- `tag_not_found` はトースト `タグ「〈名〉」はもう無いため、一覧を取り直しました` を示し、ポップオーバーの候補を取り直したタグの一覧から作り直す。選択は残る。

## タグ管理ページ {#tag-management-page}

### レイアウト {#layout}

- 本体の幅と余白は設定ページと同じ (`mx-auto max-w-4xl px-4 py-6 sm:px-6 sm:py-8`)。上から `h1` `タグ`、操作の行、件数の行、タグの一覧である。トップバーには何も置かない。
- 操作の行は、左に検索の入力欄 (ライブラリの `SearchBox` と同じ見た目。プレースホルダーとアクセシブルな名前は `タグを検索`。`flex-1 sm:max-w-sm`)、右に secondary の `Button` `新しいタグ` (lucide `Plus`) を置く。検索の入力欄は本体で最初の Tab の止まり先である (`UI品質`「管理ページでは検索の入力欄にキーボードだけで届く」)。`/` キーで検索の入力欄へ移る。ライブラリの検索ボックスと同じである。
- 件数の行は `text-xs text-fg-muted tabular-nums`、`role="status"`、`aria-live="polite"` で、`12 個のタグ`、検索中は `3 / 12 個のタグ` である。

### 行 {#rows}

- 一覧は `divide-y divide-border` の行で (設定ページのメディアフォルダと同じ)、枠やカードで囲まない。各行は `py-2` で、多くのタグを見渡せる密度にする (`UI品質`「情報の密度」)。
- 行は左から、名前の列 (`flex-1 min-w-0`)、件数、操作である。

| 部分 | 形 |
| --- | --- |
| 名前 | `text-sm font-medium text-fg`、1 行で省略し、完全な名前は `title`。`/?tag=<id>` へのリンク (要件 6、「移動」)。ホバーで `text-link`。アクセシブルな名前は `〈名〉で絞り込んだライブラリを開く` |
| シノニム | 名前の下に `text-xs text-fg-muted` の 1 行、`シノニム: anime · アニメ`。ないときは行を置かない。1 行に省略し、完全な文字列は `title` |
| 件数 | `text-sm text-fg-muted tabular-nums`、右寄せの `w-16`、`12 本`。0 は `0 本` と示す |
| 操作 | `IconButton` (ghost、`sm`) の `改名` (`Pencil`) と `シノニム` (lucide `Tags`)、続いて `その他の操作` のメニュー (lucide `Ellipsis`)。メニューには `別のタグへ統合…` (`Merge`)、区切り線、`削除…` (`Trash2`、`text-danger`) が入る |

- 削除と統合は取り消せないので、行ではなくメニューに置く (`UI品質`「削除と統合は作成と改名より目立たなくする」)。設定ページのメディアフォルダは行に削除を置くが、その行の操作は 2 つだけである。ここでは 4 つあるので、行を軽く保つほうを取る。
- 階層: 名前が主で、件数とシノニムは従である (`UI品質`「視覚的な階層」)。

### 作成と改名 {#create-and-rename}

- `新しいタグ` は一覧の先頭に入力の行を差し込み、そこへフォーカスを移す。入力欄は「コンボボックス」と同じく検証して理由を示すが、候補の一覧は持たない。Enter で作成し、Esc か `キャンセル` で閉じる。行の右には primary の `sm` の `Button` `作成` と、ghost の `sm` の `キャンセル` を置く。作成すると、行は名前の順の位置に入り、フォーカスはその名前へ移る。
- `改名` は行の名前を同じ入力欄に置き換え、今の名前を選んだ状態でフォーカスする。Enter で確定し、Esc で元に戻す。確定した後、フォーカスは `改名` へ戻る。
- 名前が既存の名前やシノニムとぶつかるとき (`tag_name_taken`)、サーバーの `message` (`「anime」は「Anime」のシノニムです` の形) を入力欄の下に `text-xs text-danger` で示し、入力欄は残る。

### シノニム {#synonyms}

- `シノニム` は `ModalFrame` のダイアログ `「Anime」のシノニム` を開く。
  - 上に、今のシノニムを × を加えた `Chip` で示す。ダイアログの面は `bg-elevated` で、中立の `Chip` と同じ色なのでチップの面が見えなくなる。そのためこのチップだけ `bg-bg` を使う (`bg` の上の `fg` は `pairs` にある)。× のアクセシブルな名前は `シノニム「アニメ」を解除` である。確認なしにすぐ解除する (名前を空けるだけで、動画のタグは変わらない)。
  - 下に、`シノニムを追加` の入力欄 (「コンボボックス」と同じく検証し、候補はない) と secondary の `Button` `追加` を置く。
  - 名前がほかのタグのシノニムとぶつかるときは、`message` (どのタグのシノニムか) を入力欄の下に示す (Edge Case `シノニム名の衝突`)。
- 加える名前が既存のタグの名前のとき (要件 6、「シノニムの追加」)、同じダイアログが確認に切り替わる。
  - 文言: `「anime」は 10 本の動画に付いているタグです。「Anime」に統合すると、その 10 本に「Anime」が付き、「anime」とそのシノニムは「Anime」のシノニムになります。「anime」はタグの一覧から消えます。` シノニムのないタグでは `とそのシノニム` を省く (Edge Case `統合とシノニム`)。件数は `GET /api/tags` の `videoCount` である (受け入れ条件 17)。
  - 操作: secondary の `Button` `戻る` (最初のフォーカス) と danger の `統合する`。`戻る` は何も変えずに入力欄へ戻り、入力欄の文字は残す。
  - `tag_merge_required` のときは、タグの一覧を取り直し、新しい件数で確認をもう一度示す。

### 統合と削除 {#merge-and-delete}

- `別のタグへ統合…` は `ModalFrame` のダイアログ `「X」を統合` を開く。統合元は行のタグで、統合先は「コンボボックス」で選ぶ (統合元を除くすべてのタグ、作成の行なし)。選ぶと、確認 `「X」が付いた 5 本の動画に「Y」が付きます。「X」とそのシノニムは「Y」のシノニムになり、「X」はタグの一覧から消えます。この操作は取り消せません。` が下に現れる。操作は secondary の `キャンセル` と danger の `統合する` で、`統合する` は統合先を選ぶまで `disabled` である。
- `削除…` は文言 `12 本の動画からこのタグが外れます。この操作は取り消せません。` (受け入れ条件 11)、動画が 0 本なら `このタグはどの動画にも付いていません。` のダイアログ `「X」を削除` を開く。操作は secondary の `キャンセル` (最初のフォーカス) と danger の `削除する` である。
- 実行中は両方のボタンが `disabled` になり、danger のボタンは `LoaderCircle` を示す (設定ページのフォルダ変更の確認と同じ)。
- 終わるとダイアログを閉じ、トーストで `統合しました` または `削除しました` と伝える。フォーカスは、統合の後は統合先の行の名前へ、削除の後は次の行の `改名` へ、なければ前の行のものへ、行が残っていなければ `新しいタグ` へ移る。

### 状態 {#states-1}

| 状態 | 画面が示すもの |
| --- | --- |
| 読み込み中 | 件数の行は `読み込み中…`。一覧の代わりに `Skeleton` の行 (`h-10`) を 6 つ |
| 読み込みに失敗 | `EmptyState` (danger、`AlertCircle`) `タグを取得できません`、`Button` `再試行` |
| タグなし | `EmptyState` (lucide `Tags`) `タグはまだありません`、説明 `動画の再生画面や、ライブラリの選択バーから付けられます。ここで先に作っておくこともできます。`、primary の `Button` `新しいタグ`。検索の入力欄は見えたままで `disabled` になる |
| 検索に一致なし | `EmptyState` (`SearchX`) `「〈入力〉」に一致するタグはありません`、`Button` `検索をクリア`。押すと入力欄を空にしてそこへフォーカスを移す。「タグなし」とは見出しとアイコンで見分ける |
| 操作に失敗 | ダイアログの中か入力欄の下に `text-sm text-danger` の 1 行 (`role="alert"`)。ダイアログと入力欄は開いたまま |
| タグがもう無い (`tag_not_found`) | ダイアログを閉じ、トーストで `このタグはもう無いため、一覧を取り直しました` と伝える。一覧を取り直す |

## ほかの画面の古くなったタグ {#stale-tags-in-other-screens}

- すべて選択の応答に `missingTagIds` があるときは、選択を作らない。削除されたタグを絞り込みから外して知らせる。利用者は直った一覧でもう一度すべて選択を押す ([tags-api.md、一覧の絞り込みとすべて選択](contracts/tags-api.md#list-filter-and-select-all))。
- ライブラリの URL の `tag` にもう無いタグが含まれるとき (`missingTagIds`、またはスナップショットから戻すときの確認)、トーストで `削除されたタグを絞り込みから外しました` と伝え、そのチップは絞り込み中のタグの行から消える ([list-url.md、パラメーター](contracts/list-url.md#parameters))。外したタグの名前はタグの一覧から分からないことがあるので、文言には含めない。
- カードと動画ページのタグは、一覧か動画を次に取得するまで古い名前のままのことがある。それを押して `tag_not_found` か `missingTagIds` が返ったときは、画面が上のとおりに知らせて直す。

## 操作の状態 {#interaction-states}

加えるコントロール (チップ、`+N`、候補の行、選択バーのボタン、管理ページの行の操作) は、ホバー、focus-visible、active、disabled を基になるコンポーネント (ghost と secondary の `Button`、`IconButton`、`ui/Menu` の項目、`Chip`) から受け継ぐ。独自の状態の色は作らない。動画のタグのチップはホバーで文字が `text-fg` になり、内側に `ring-1 ring-inset ring-border-strong` の縁を示す。面の色は変えない。`elevated` より明るい不透明な面のトークンがないからである。フォーカスは共通の `:focus-visible` (`link` の色の外側の輪郭) である。カードの中のタグにフォーカスがあるときは、カードの外側の輪郭 (`has-[a:focus-visible]`) は出ず、チップの輪郭だけが出るので、リンクとタグのどちらにフォーカスがあるかが分かる。

## アクセシビリティ {#accessibility}

- アクセシブルな名前:

| コントロール | 名前 |
| --- | --- |
| 動画のタグ (カード、動画ページ、`+N` の中) | `〈名〉で絞り込む` |
| 絞り込み中のタグ | `〈名〉の絞り込みを外す` |
| 動画ページの × | `〈名〉をこの動画から外す` |
| `+N` | `ほかのタグ N 個を表示` |
| 管理ページの名前のリンク | `〈名〉で絞り込んだライブラリを開く` |
| 選択バーの一部にだけ付く候補 | `〈名〉、一部の動画だけ、N 件中 M 件` |

- グループ化: カードのタグは `aria-label="タグ"` の `ul`、絞り込み中のタグは `aria-label="絞り込み中のタグ"` の `ul`、動画ページは隠した `h2` `タグ` の下の `ul` である。
- 検証の理由には入力欄の `aria-describedby`、操作の失敗には `role="alert"`、件数の変化には `role="status"` (`polite`) を使う。
- 色の組: 文字に使う組のうち、`elevated` の上の `fg` と `fg-muted` (チップ、候補)、`bg` の上の `fg` (ダイアログのシノニムのチップ)、`bg` の上の `danger` (動画ページと管理ページの本体の理由と失敗の行) は、すでに `tokens.test.ts` の `pairs` にある。`elevated` の上の `danger` は `pairs` にない (計算で約 5.9 で、4.5 を満たす)。これは選択バーのポップオーバーと管理ページのダイアログの中 (`ModalFrame` は `bg-elevated`) の理由と失敗の行に使う。この選択バーの組を `pairs` に加える。絞り込み中のタグの `accent-soft` の上の `link` は、今の `Chip` のアクセントと同じ組である。`accent-soft` は半透明なので `pairs` の外にある (`tokens.test.ts` は 6 桁の 16 進の値しか読まない)。新しいトークンは加えない。
