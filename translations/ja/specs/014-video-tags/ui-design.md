# UI 設計: 動画のタグとタグでの絞り込み {#ui-design-video-tags-and-tag-filtering}

**Feature**: [親 Issue #193](https://github.com/syudead/vv/issues/193)

出典: 見た目の規則、シェル、一覧の密度は [ライブラリ UI: 見た目の規則と一覧の構造](../../docs/design-docs/library-ui.md) と [`web/src/index.css`](../../web/src/index.css) の `@theme` に従う。動画ページの構造は [012 の ui-design.md](../012-video-detail-ia/ui-design.md) に従う。ツールバー、一致なしの状態、`条件を解除` は [013 の ui-design.md](../013-library-search/ui-design.md) に従う。URL の形と履歴は [contracts/list-url.md](contracts/list-url.md) で、エラーの `code` と件数は [contracts/tags-api.md](contracts/tags-api.md) で決まっている。この文書はそれらを蒸し返さない。この文書が定めるのは、カードのタグ行、絞り込み中のタグ、動画ページのタグ、選択バーのタグ操作、タグ管理ページが既存の画面に**加えるもの、または変えるもの**だけだ。新しい色、角丸、影のトークンは加えない。

## 画面の境界 {#screen-boundary}

| 場所 | この機能が加えるもの |
| --- | --- |
| ライブラリ (`/`) のグリッドのカード | 題名の下のタグ行。ライブラリのリスト表示の行にはタグ行がない。フォルダ画面のカードにも同じタグ行がある。タグを押すと、そのタグで絞り込んだライブラリ (`/?tag=<id>`) へ移る |
| ライブラリの本体の上端 | タグで絞り込んでいる間だけ、要約行の上に絞り込み中のタグの行を置く。ツールバー (上部バーの中) には何も加えない |
| 動画ページ (`/videos/:id`) | 題名の下のタグの一覧 |
| 選択バー | タグを一括で付ける操作と外す操作。[library-ui.md、一覧のレイアウト](../../docs/design-docs/library-ui.md#list-layout) に従って置く |
| タグ管理ページ (`/tags`) | `AppShell` の中。サイドバーの `フォルダ` の直後に `タグ` の項目 (lucide の `Tags`) を置く |

## タグチップ {#tag-chip}

タグは役割の違う 3 つの形で現れる。どれも見た目の骨格 (`h-5` か `h-6`、`rounded-sm`、`px-1.5` から `px-2`、`text-xs`、1 行で切り詰め) を共有し、色と印で見分ける。

| 形 | 場所 | 面と文字 | 印 | 押したとき |
| --- | --- | --- | --- | --- |
| 動画のタグ | カード、動画ページ | `bg-elevated`、`text-fg-muted` (動画ページでは `text-fg`) | なし | そのタグで絞り込む |
| 絞り込み中のタグ | 一覧の上 | `bg-accent-soft`、`text-link` (今の `Chip` のアクセント) | 先頭に lucide の `Tag`、末尾に `X` | その絞り込みを外す |
| 候補、集計 | 候補の一覧、選択バー | 行の形 (後述の「コンボボックス」) | 一部だけに付いているときの文言 | 付ける、または外す |

- 長い名前は、チップの文字に `min-w-0 truncate` を付けて末尾で切り詰め、`title` に全体の名前を入れる。チップの最大幅はその行の幅 (`max-w-full`) なので、100 文字の名前でも 360px で横にはみ出さない。
- アクセントの色を持つのは絞り込み中のタグだけだ。動画のタグは中立の色のままなので、色でも一覧がどのタグで絞り込まれているかがわかる。色だけが手がかりではない。絞り込み中のタグには `Tag` のアイコンと、行の先頭の文言 (後述の「絞り込み中のタグ」) もある (`UI品質` の「アクセシビリティ」)。

## ライブラリのカード {#library-card}

### タグ行 {#tag-row}

- 題名の `h3` のすぐ下、今メタデータの行がある場所に 1 行置く。題名との間は今の `gap-1`、下の余白は今の `pb-3` のままにする (`UI品質` の「余白のリズム」)。
- 行は `flex flex-nowrap gap-1 overflow-hidden` だ。チップは `gap-1` で等間隔に、API の順序 (名前の自然な順序) で並べる。
- 行とカードの `article` はどちらも中身を切り取るので、全体の `:focus-visible` の外側の輪郭はチップの外で切れてしまう。カードのチップ (と `+N`) だけは輪郭をチップの内側に描く (`focus-visible:outline-offset-[-2px]`)。色と幅は全体のままだ。
- チップは `h-5`、`text-xs` で、題名 (`text-sm font-medium`) より小さく `text-fg-muted` なので、題名より先に目を引かない。視聴済みのカードでは題名も `text-fg-muted` だが、大きさとチップの面でやはり見分けられる。
- タグのない動画には行がなく、「タグなし」の文言もない。空の行は分類がないことを空白で伝えることになり、何も伝えない。グリッドの各行のカードは今と同じく高さがそろう (`flex-wrap` の既定の `stretch`)。
- 行はカードの下端に置くので、題名が 1 行でも 2 行でも、グリッドの行の中でタグ行の位置がそろう。そのために `flex-1` で伸びるのは行ではなくカードのリンクで、題名と行の間の空きはリンクの領域 (押すと開くか選択する) に属する。

### はみ出し {#overflow}

- 1 行に収まらないタグは行の末尾の `+N` チップに置き換え、収まるチップだけを表示する (`UI品質` の「情報密度」)。`+N` は動画のタグの形で、文字は `tabular-nums` だ。フェードアウトは採らない。名前が切れたのか、ほかにもタグがあるのかがわからない。
- `+N` はボタンだ。隠れたタグを同じチップで縦に並べた `ui/Popover` を開く。チップを押すと、カードの行と同じくそのタグで絞り込み、ポップオーバーを閉じる。アクセシブルな名前は `ほかのタグ N 個を表示` だ。
- 収まるチップの数は、描画した後に行とチップの幅を測って決める。CSS だけではその数を出せない。library-ui.md、[幅のブレークポイントは CSS に置き、サイドバーは例外とする](../../docs/design-docs/library-ui.md#width-breakpoints-in-css-and-the-sidebar-exception) が避けているのは JavaScript での画面幅による分岐で、中身が収まるかを測ることとは違う。測る前の 1 フレームで行が伸び縮みしないように、数は描画の前 (レイアウトエフェクト) で決め、カードの大きさか画面幅が変わったときに測り直す。カードごとに 1 つの監視を置く代わりに、一覧に置いた 1 つの `ResizeObserver` が描画したカードの行を監視する (library-ui.md、[長い一覧の仮想スクロール](../../docs/design-docs/library-ui.md#virtual-scrolling-of-long-lists))。カードの幅はズームの段階ごとに一定なので、測り直すのはズームの段階か画面幅が変わったとき、またはタグが変わったときだけだ。
- 一覧は、行の幅ごと、チップの幅を決める入力 (名前、仮のタグの印、フォルダ由来の印) ごとに数を保持するので、スクロールで離れた後にもう一度描画したカードは、チップを測らずにその数を使う。

### カードの構造と押したとき {#card-structure-and-pressing}

- 今はカード全体が動画ページへの 1 つのリンクだ。タグ行はリンクの**外**、同じ `article` の中で題名の下に置く (リンクの中に操作できる要素を入れ子にしない)。区切り線はなく、見た目は 1 枚のカードのままだ。
- カードのホバーでの浮き上がり、影、ホバーでのプレビューは、今と同じくタグ行の上でも働く。
- 各タグチップはボタンだ。押すとそのタグを今の条件に加え ([list-url.md、タグを加える、外す](contracts/list-url.md#adding-and-removing-a-tag))、動画ページへは移らない。すでに絞り込み中のタグを押しても何も変わらず、チップの見た目もほかと同じだ (絞り込み中の印は一覧の上にだけ現れる)。
- 16 個が絞り込み中のときに 17 個目のタグを押しても加えず、トーストで `絞り込めるタグは 16 個までです` と伝える。
- **選択中** (1 件以上を選んでいるとき) は、タグチップをボタンとして描かない。文字と面は残り、押すとカードの選択が切り替わる (Edge Case `選択中にタグを押したとき`)。Tab の順序からも外れる。選択中にタグの名前で「絞り込む」と読み上げると、押したときの動作と食い違う。`+N` も操作できなくなる。
- カードの中のキーボードの順序: チェックボックス → リンク (題名) → タグ → `+N`。

## 絞り込み中のタグ {#active-tag-filters}

- ライブラリの本体の上端、要約行の上に 1 行置き、タグで絞り込んでいる間だけ表示する。タグの絞り込みがなければ場所を取らない。
- 行は要約行と同じく中央にそろえる (`flex flex-wrap justify-center items-center gap-1.5`)。`text-xs text-fg-muted` の文言 `タグで絞り込み中` で始まり、続けて絞り込み中のタグを名前の自然な順序で並べ、収まらなければ折り返す。
- 各チップは `Tag` のアイコン、名前、`X` のアイコンを持つ 1 つのボタンで、どこを押してもそのタグだけを外す (`UI品質` の `ワンクリックで届き`)。× だけを小さな的にする案は採らない。チップ全体の操作は 1 つなので、的を小さくする理由がない。ホバーで内側の `ring-1 ring-inset ring-border-strong` の縁が現れる (動画のタグチップと同じ)。文字の色を変える案は採らない。`accent-hover` と `link` は同じ値なので、見た目が何も変わらない。
- 外した後、フォーカスは次のチップへ、なければ前のチップへ、最後の 1 つだったときは検索欄へ移る。外したチップは消え、フォーカスの行き先も一緒に消えてしまう (013 の一致なしの状態と同じ)。
- 階層: 行はツールバーの下の本体にあり、ツールバーの部品より小さい (`h-6`、`text-xs`)。グリッドより先に目を引くアクセントの面はこれだけなので、今の条件がひと目で読める。
- タグの一覧を読み込むまでは、各チップは名前の代わりに `Skeleton` (`w-12`) を URL の `id` ごとに 1 つ持ち、読み込んだら名前に置き換える。
- 絞り込みメニューの `条件を解除` (013 の「絞り込みメニュー」) はタグで絞り込んでいる間も現れ、押すとタグの絞り込みも外す。タグは絞り込みボタンの数に数えない ([list-url.md、タグを加える、外す](contracts/list-url.md#adding-and-removing-a-tag))。
- 要約行は形を変えず、タグの名前を含めない。その件数は `tag` を含めた `total` だ。
- 一致なしの状態 (013 の「一致なしの状態」) は、013 の今の契約 (PR #262) のとおり、検索語、絞り込み、検索範囲のチップや注記を持たず、`条件を解除` ボタンも持たない。タグの絞り込みも同じに扱い、一致なしの状態の中にチップも外す操作も加えない。絞り込み中のタグが見えるのは一致なしの状態の上のこの行だけで、ここか、絞り込みメニューの `条件を解除` (タグを含めてすべてを外す) で外す。
- 検索語、視聴状態、再生できるか、タグを変えると選択を解除するので、条件の違う一覧で選んだ動画が、見えないまま選ばれ続けることはない。

## 動画ページのタグ {#video-page-tags}

### 置き場所 {#placement}

- 題名 (`h1`) のすぐ下。タグは動画を分類し、題名と一緒に読まれる。カードでも題名のすぐ下に表示するので、一覧から開いたときも順序が同じだ。
- 題名とタグの一覧で 1 つのまとまり (`flex flex-col gap-2`) を作り、まとまりと区切りの間は今の `gap-5` にする。題名とタグの間を `gap-5` にすると、タグが属性の側に属するように見えてしまう。
- 012 の「題名の下にチップやボタンを置かない」(見た目のレビュー基準、「情報密度」) は、この機能がタグの一覧についてだけ改める。要約行、ボタン、ほかのチップは今までどおり題名の下に置かない。
- 階層は、小さなチップ (`h-6`、`text-xs`) と中立の面で保ち、題名 (`text-xl` から `text-2xl`、`font-semibold`) より先に目を引かない (`UI品質` の「視覚的な階層」)。
- ラベル (`TAGS` など) は置かない。チップの形でタグだとわかり、題名のすぐ下にラベルの行があると散らかる。まとまりの見出しは、見た目には隠した `h2` の `タグ` だ。
- 一覧は `flex flex-wrap items-center gap-1.5` だ。付いているタグのチップの後に、`タグを追加` の入力欄を同じ行に置く。行は折り返す。

### チップ {#chip}

- `h-6`、`text-xs`、`bg-elevated`、`text-fg`。名前の部分 (リンク) と × の部分 (ボタン) に分け、その間に `bg-border-strong` の縦線 (`w-px h-3.5`) を引く。

| 部分 | 要素 | 押したとき | アクセシブルな名前 |
| --- | --- | --- | --- |
| 名前 | `/?tag=<id>` への `Link`。移動するのでボタンではなくリンクにし、新しいタブでも開ける (管理ページの名前と同じ) | このタグ 1 つで絞り込んだライブラリの一覧を開く | `〈名〉で絞り込む` |
| × | `size-6` の正方形、lucide の `X` (`size-3`) | この動画からタグを外す | `〈名〉をこの動画から外す`。絞り込み中のタグの `〈名〉の絞り込みを外す` とは文言で区別する (`UI品質` の「アクセシビリティ」) |

- 外した後、フォーカスは次のチップの × へ、なければ前のチップの × へ、最後の 1 つだったときは `タグを追加` の入力欄へ移る。
- チップはサーバーが応答した後に加えるか外す。待つ間、その × は `disabled` で、入力欄は「コンボボックス」で述べる送信中の状態になる。

### 追加の入力欄 {#add-input}

- 部品は後述の「コンボボックス」だ。入力欄は `h-6`、`w-40`、`bg-field`、`border-border`、`rounded-sm`、`text-xs` で、左に lucide の `Plus` (`size-3`、`text-fg-muted`)、プレースホルダーは `タグを追加` だ。フォーカスで `border-accent` (検索欄と同じ)。
- 確定すると入力欄は空になり、フォーカスを保つので、すぐに別のタグを加えられる。新しいチップは名前の順序の位置に入る。
- 入力欄にフォーカスがある間、動画ページのキー (Space、←→、F、M、0、Esc) は働かない (`keyboard.ts` の今の `isEditable`)。Esc は、候補の一覧が開いていれば閉じ、そうでなければ入力を消す。空の入力欄での Esc は何もしない。ページを閉じるのは入力欄の外で押した Esc だけだ。

### 状態 {#states}

| 状態 | 画面に出るもの |
| --- | --- |
| 詳細を読み込み中 | タグの一覧はない (題名と同じくスケルトンの中) |
| タグがない | 題名の下に `タグを追加` の入力欄だけ |
| 付ける、外すのに失敗 | 一覧のすぐ下に `text-xs text-danger` の 1 行 (`role="alert"`): `タグを付けられませんでした` または `タグを外せませんでした`。入力の文字は残り、Enter でやり直す。次の操作で消える |
| タグがもう無い (`tag_not_found`) | トースト `タグ「〈名〉」はもう無いため、一覧を取り直しました`。タグの一覧とこの動画を取り直す |

## コンボボックス {#combobox}

動画ページの `タグを追加`、選択バーの `タグを付ける` と `タグを外す`、管理ページの統合先の選択は、1 つの部品 (`web/src/ui/Combobox.tsx`) を使う。ARIA 1.2 のコンボボックス (入力欄 + リストボックス、`aria-activedescendant`) だ。

- 候補の一覧は入力欄の下 (選択バーでは上) に、`ui/Popover` と同じ面 (`bg-elevated`、`shadow-elevated`、`rounded-md`) で現れる。幅は `w-64` で、8 行を超えるとスクロールする。フォーカスで開き、入力欄が空のときはすべての候補を表示する。
- 見えている行と、その両側の数行だけを描画するので、数千のタグの一覧も止まらずに開き、絞り込める (#675)。アクティブな行は見える範囲の外へスクロールした後も描画したまま保つので、`aria-activedescendant` は常に要素を指す。各行は `aria-setsize` と `aria-posinset` を持つので、スクリーンリーダーは一覧全体での位置を読み上げる。畳み込んだ名前と自然な順序はタグの一覧ごとに 1 回だけ用意し、キーを打つたびにはそれを絞り込むだけだ。
- 候補の行は `h-8`、`px-2.5`、`text-sm` だ。名前は `text-fg` で 1 行に切り詰め、右に副次的な情報を `text-xs text-fg-muted tabular-nums` で置く (管理ページと同じく件数。選択バーの外す候補では後述の「一部」の印)。アクティブな行は `bg-hover-wash` (メニューの項目と同じ)。
- 絞り込み: 名前かシノニムが入力を含むタグを、大文字と小文字を区別せずに残す (管理ページの検索と同じ)。前方一致を先に、次に名前の自然な順序で並べる。シノニムで一致したタグは、名前の下に `text-xs text-fg-muted` で `シノニム: アニメ` と表示する。表示する名前は常に元の名前だ (要件 7)。
- 動画にすでに付いているタグは `タグを追加` の候補に出さない。
- 入力の綴りと正確に一致する名前もシノニムもないとき、一覧の末尾に `「〈入力〉」を作成` の行 (lucide の `Plus`) を置く。`Anime` があるときに `anime` と打つと、この行が出る (要件 4)。正確に一致するものがあれば出ない。

キー:

| キー | 動作 |
| --- | --- |
| ↓、↑ | 行の間を移る。端で止まる |
| Enter、アクティブな行がある | その行を確定する |
| Enter、アクティブな行がない | 入力の綴り (前後の空白を除く) を確定する。名前かシノニムが一致するタグ、なければ新しいタグだ。作成の行のない形 (選択バーの `タグを外す`、統合先) は、綴りが候補の名前かシノニムと正確に一致するときだけ確定し、そうでなければ何もしない |
| Tab | 確定せずに一覧を閉じて先へ進む |
| Esc | 一覧が開いていれば一覧だけを閉じる。ポップオーバーかダイアログの中のコンボボックスで一覧が閉じているときは、そのポップオーバーかダイアログだけを閉じる。どちらでも Esc はそこで止まり、外側 (選択の解除、動画ページを閉じる) には届かない。動画ページの入力欄での Esc は上の「追加の入力欄」のとおりに働く |

- 名前の検証 (要件 4): 入力のたびに確かめる。名前を作れないときは、入力欄の下の `text-xs text-danger` の 1 行で理由を示し、Enter を受け付けない。理由は `改行やタブは使えません` と `100 文字以内にしてください（今 101 文字）` だ。空か空白だけの入力は、打っている間は理由を示さない (確定の後や開いたときの空の入力欄は普通の状態だ)。その状態で Enter を押したときだけ `名前を入力してください` を示す。文字数は、サーバーと同じく前後の空白を除いた名前のコードポイントで数え ([data-model.md、名前の規則](data-model.md#name-rules))、JavaScript の `length` (UTF-16 の単位) では数えない。入力欄には `maxLength` を付けない。付けると 101 文字目が黙って落ち、理由を示す手段がない。入力欄の `aria-describedby` は理由の行を指す。
- 入力欄の値からは改行を見つけられない。1 行の `input` は値に届く前に改行 (LF、CR) を取り除くので、`旅行\n2024` を貼り付けると `旅行2024` になり、別の名前を確定してしまう。そこで元の文字列を、貼り付け (`paste` の `clipboardData`) とドロップ (`beforeinput` の `insertFromDrop`) の時点で確かめる。改行を含むときは入力を取り込まず (`preventDefault`)、値は元のままで、理由 `改行やタブは使えません` が現れる。理由は次に入力が変わるまで残り、それまでは Enter も確定のボタン (`作成`、`追加` など) も受け付けない。入力欄には貼り付けの前の名前がまだ入っており、確定すると利用者が貼り付けた名前ではなくその名前を確定してしまう。入力が変わると理由は消え、新しい値は確定を受け付ける前に上の検証を通る。改行のない部分だけを取り込む案は採らない。貼り付けたものと違う名前が黙って入力欄に入ってしまう。タブとほかの制御文字は値に残り、入力ごとの検証で捕まる。この扱いは、タグの名前を打つすべての入力欄 (「コンボボックス」と、管理ページの作成、改名、シノニムの追加) で同じだ。
- 送信中、入力欄は `aria-busy="true"` を持ち、Enter を受け付けない。入力欄の右端に `LoaderCircle` (`size-3`、`animate-spin`) を表示する。

## 選択バー {#selection-bar}

2 つのタグ操作は 1 つのメニューにまとめない。狭い幅では手順が 1 つ増えるからだ。

### 付ける {#add}

- 押すと、バーの上に「コンボボックス」を収めた `ui/Popover` を開く (今の `PopoverContent` は方向を取らないので、上へ開くための `side` プロパティを加える)。フォーカスは入力欄へ移る。候補はすべてのタグで、各行の右に件数を置く。確定すると、選んだすべての動画にタグを付け、ポップオーバーを閉じ、トーストで `N 件に「〈名〉」を付けました` と伝える。フォーカスは `タグを付ける` へ戻る。
- 付けた後も選択は残るので、続けてほかのタグを付けたり外したりできる。

### 外す {#remove}

- 押すと同じ種類のポップオーバーを開き、選んだ動画のタグの集計を取りに行く。届くまで、ポップオーバーは `読み込み中…` (`text-xs text-fg-muted`、`role="status"`) を表示する。
- 中身は作成の行のない「コンボボックス」で、候補は集計にあるタグだけだ。各行の右に、すべての動画に付いているタグは `3 件` を、一部だけに付いているタグは lucide の `CircleDashed` (`size-3`) と `一部 1 / 3 件` を表示する (要件 2)。色は変えない。`一部` という語とアイコンで見分け、行のアクセシブルな名前は `一部の動画だけ、3 件中 1 件` を含む。
- 確定すると、選んだすべての動画からタグを外し、トーストで `N 件から「〈名〉」を外しました` と伝える。
- 選んだ動画のどれにもタグがないとき、ポップオーバーは `選んだ動画にタグはありません` を表示する。
- 集計を取れないとき、ポップオーバーは `text-xs text-danger` の 1 行 (`role="alert"`) `タグを取得できませんでした` と、ゴーストの `sm` の `Button` `再試行` を表示する。選択は残る。

### 失敗 {#failure}

- 失敗したとき、ポップオーバーは開いたままで、入力欄の下に `text-xs text-danger` の 1 行 (`role="alert"`) を出す: `付けられませんでした。もう一度お試しください` または `外せませんでした。もう一度お試しください`。選択と入力の文字は残り、Enter でやり直す (Edge Case `一括操作の途中失敗`)。
- `tag_not_found` ではトースト `タグ「〈名〉」はもう無いため、一覧を取り直しました` を出し、ポップオーバーの候補は取り直したタグの一覧から作り直す。選択は残る。

## タグ管理ページ {#tag-management-page}

### レイアウト {#layout}

- 本体の幅と余白は設定ページと同じ (`mx-auto max-w-4xl px-4 py-6 sm:px-6 sm:py-8`)。上から、`h1` の `タグ`、操作の行、件数の行、タグの一覧。上部バーには何も置かない。
- 操作の行は、左に検索の入力欄 (ライブラリの `SearchBox` と同じ見た目。プレースホルダーとアクセシブルな名前は `タグを検索`。`flex-1 sm:max-w-sm`)、右にセカンダリの `Button` `新しいタグ` (lucide の `Plus`) を置く。検索の入力欄は本体で最初の Tab の止まり先だ (`UI品質` の「管理ページでは検索の入力欄にキーボードだけで届く」)。`/` キーは、ライブラリの検索欄と同じく検索の入力欄へ移る。
- 件数の行は `text-xs text-fg-muted tabular-nums`、`role="status"`、`aria-live="polite"` で、`12 個のタグ`、検索中は `3 / 12 個のタグ` だ。

### 行 {#rows}

- 一覧は `divide-y divide-border` の行で (設定ページのメディアフォルダと同じ)、周りに枠もカードもない。各行は `py-2` で、多くのタグを見渡せる密度だ (`UI品質` の「情報密度」)。
- 行は左から、名前の列 (`flex-1 min-w-0`)、件数、操作を持つ。

| 部分 | 形 |
| --- | --- |
| 名前 | `text-sm font-medium text-fg`、1 行で切り詰め、全体の名前を `title` に入れる。`/?tag=<id>` へのリンク (要件 6、「移動」)。ホバーで `text-link`。アクセシブルな名前は `〈名〉で絞り込んだライブラリを開く` |
| シノニム | 名前の下に `text-xs text-fg-muted` の 1 行、`シノニム: anime · アニメ`。なければ行はない。1 行で切り詰め、全体を `title` に入れる |
| 件数 | `text-sm text-fg-muted tabular-nums`、右寄せの `w-16`、`12 本`。0 は `0 本` と表示する |
| 操作 | `IconButton` (ゴースト、`sm`) の `改名` (`Pencil`) と `シノニム` (lucide の `Tags`)、続けて `その他の操作` のメニュー (lucide の `Ellipsis`)。メニューには `別のタグへ統合…` (`Merge`)、区切り、`削除…` (`Trash2`、`text-danger`) を入れる |

- 削除と統合は取り消せないので、行ではなくメニューに置く (`UI品質` の「削除と統合は作成と改名より目立たなくする」)。設定ページのメディアフォルダは削除を行に置くが、その行の操作は 2 つしかない。ここでは 4 つあるので、行を軽く保つほうを取る。
- 階層: 名前が主で、件数とシノニムは副次的だ (`UI品質` の「視覚的な階層」)。

### 作成と改名 {#create-and-rename}

- `新しいタグ` は一覧の先頭に入力の行を差し込み、フォーカスをそこへ移す。入力欄は「コンボボックス」と同じく検証して理由を示すが、候補の一覧はない。Enter で作成し、Esc か `キャンセル` で閉じる。行の右にプライマリの `sm` の `Button` `作成` とゴーストの `sm` の `キャンセル` を置く。作成すると、行は名前の順序の位置に入り、フォーカスはその名前へ移る。
- `改名` は行の名前を同じ入力欄に置き換え、今の名前を選択した状態でフォーカスする。Enter で確定し、Esc で元に戻す。確定の後、フォーカスは `改名` へ戻る。
- 名前が既存の名前かシノニムとぶつかるとき (`tag_name_taken`)、サーバーの `message` (`「anime」は「Anime」のシノニムです` の形) を入力欄の下に `text-xs text-danger` で表示し、入力欄は残る。

### シノニム {#synonyms}

- `シノニム` は `ModalFrame` のダイアログ `「Anime」のシノニム` を開く。
  - 上に、今のシノニムを × を加えた `Chip` で並べる。ダイアログの面は `bg-elevated` で、中立の `Chip` と同じ色なのでチップの面が消えてしまう。そのためこのチップだけは `bg-bg` を使う (`bg` の上の `fg` は `pairs` にある)。× のアクセシブルな名前は `シノニム「アニメ」を解除` だ。外すのは確認なしにすぐ行う (名前を空けるだけで、動画のタグは変わらない)。
  - その下に、`シノニムを追加` の入力欄 (「コンボボックス」と同じく検証し、候補はない) とセカンダリの `Button` `追加` を置く。
  - 名前がほかのタグのシノニムとぶつかるとき、`message` (どのタグのシノニムか) を入力欄の下に表示する (Edge Case `シノニム名の衝突`)。
- 加える名前が既存のタグの名前のとき (要件 6、「シノニムの追加」)、同じダイアログが確認に切り替わる。
  - 文言: `「anime」は 10 本の動画に付いているタグです。「Anime」に統合すると、その 10 本に「Anime」が付き、「anime」とそのシノニムは「Anime」のシノニムになります。「anime」はタグの一覧から消えます。` シノニムのないタグでは `とそのシノニム` を省く (Edge Case `統合とシノニム`)。件数は `GET /api/tags` の `videoCount` だ (受け入れ条件 17)。
  - 操作: セカンダリの `Button` `戻る` (最初のフォーカス) と危険の `統合する`。`戻る` は何も変えずに入力へ戻り、入力の文字を保つ。
  - `tag_merge_required` では、タグの一覧を取り直し、新しい件数で確認をもう一度表示する。

### 統合と削除 {#merge-and-delete}

- `別のタグへ統合…` は `ModalFrame` のダイアログ `「X」を統合` を開く。統合元は行のタグで、統合先は「コンボボックス」で選ぶ (統合元を除くすべてのタグ、作成の行なし)。選ぶと、下に確認 `「X」が付いた 5 本の動画に「Y」が付きます。「X」とそのシノニムは「Y」のシノニムになり、「X」はタグの一覧から消えます。この操作は取り消せません。` が現れる。操作はセカンダリの `キャンセル` と危険の `統合する` で、`統合する` は統合先を選ぶまで `disabled` だ。
- `削除…` はダイアログ `「X」を削除` を開き、文言は `12 本の動画からこのタグが外れます。この操作は取り消せません。` (受け入れ条件 11)、0 本なら `このタグはどの動画にも付いていません。` だ。操作はセカンダリの `キャンセル` (最初のフォーカス) と危険の `削除する`。
- 実行中は両方のボタンが `disabled` で、危険のボタンは `LoaderCircle` を表示する (設定ページのフォルダ変更の確認と同じ)。
- 終わると、ダイアログを閉じ、トーストで `統合しました` または `削除しました` と伝える。フォーカスは、統合の後は統合先の行の名前へ、削除の後は次の行の `改名` へ、なければ前の行のものへ、行が残っていなければ `新しいタグ` へ移る。

### 状態 {#states-1}

| 状態 | 画面に出るもの |
| --- | --- |
| 読み込み中 | 件数の行は `読み込み中…`。一覧の代わりに `Skeleton` の行 (`h-10`) を 6 つ |
| 読み込みに失敗 | `EmptyState` (危険、`AlertCircle`) `タグを取得できません`、`Button` `再試行` |
| タグがない | `EmptyState` (lucide の `Tags`) `タグはまだありません`、説明 `動画の再生画面や、ライブラリの選択バーから付けられます。ここで先に作っておくこともできます。`、プライマリの `Button` `新しいタグ`。検索の入力欄は見えたままで `disabled` |
| 検索に一致しない | `EmptyState` (`SearchX`) `「〈入力〉」に一致するタグはありません`、`Button` `検索をクリア`。押すと入力を消し、フォーカスを入力欄へ移す。「タグがない」とは見出しとアイコンで見分ける |
| 操作に失敗 | ダイアログの中か入力欄の下に `text-sm text-danger` の 1 行 (`role="alert"`)。ダイアログと入力欄は開いたまま |
| タグがもう無い (`tag_not_found`) | ダイアログを閉じ、トーストで `このタグはもう無いため、一覧を取り直しました` と伝える。一覧を取り直す |

## ほかの画面の古いタグ {#stale-tags-in-other-screens}

- 「すべて選択」の応答に `missingTagIds` があるとき、選択は作らず、削除されたタグを絞り込みから外して伝える。利用者は直った一覧でもう一度「すべて選択」を押す ([tags-api.md、一覧の絞り込みとすべて選択](contracts/tags-api.md#list-filter-and-select-all))。
- ライブラリの URL の `tag` がもう無いタグを含むとき (`missingTagIds`、またはスナップショットから戻すときの確認)、トーストで `削除されたタグを絞り込みから外しました` と伝え、絞り込み中のタグの行からそのチップが消える ([list-url.md、パラメーター](contracts/list-url.md#parameters))。外したタグの名前はタグの一覧からわからないことがあるので、文言には含めない。
- カードと動画ページのタグは、一覧か動画を次に取得するまで古い名前のままのことがある。それを押して `tag_not_found` か `missingTagIds` になったとき、画面は上のとおりに伝えて直す。

## 操作の状態 {#interaction-states}

加えた操作 (チップ、`+N`、候補の行、選択バーのボタン、管理ページの行の操作) は、ホバー、focus-visible、アクティブ、無効を元の部品 (`Button` のゴーストとセカンダリ、`IconButton`、`ui/Menu` の項目、`Chip`) から受け継ぐ。独自の状態の色は作らない。動画のタグチップはホバーで文字を `text-fg` にし、内側に `ring-1 ring-inset ring-border-strong` の縁を表示する。面の色は変えない。`elevated` より明るい不透明な面のトークンがないからだ。フォーカスは全体の `:focus-visible` (`link` の色の外側の輪郭) だ。カードの中のタグにフォーカスがあるとき、カードの外側の輪郭 (`has-[a:focus-visible]`) は現れず、チップの輪郭だけが現れるので、フォーカスがリンクとタグのどちらにあるかがはっきりする。

## アクセシビリティ {#accessibility}

- アクセシブルな名前:

| 操作 | 名前 |
| --- | --- |
| 動画のタグ (カード、動画ページ、`+N` の中) | `〈名〉で絞り込む` |
| 絞り込み中のタグ | `〈名〉の絞り込みを外す` |
| 動画ページの × | `〈名〉をこの動画から外す` |
| `+N` | `ほかのタグ N 個を表示` |
| 管理ページの名前のリンク | `〈名〉で絞り込んだライブラリを開く` |
| 選択バーの一部だけの候補 | `〈名〉、一部の動画だけ、N 件中 M 件` |

- まとまり: カードのタグは `aria-label="タグ"` の `ul`、絞り込み中のタグは `aria-label="絞り込み中のタグ"` の `ul`、動画ページは隠した `h2` の `タグ` の下の `ul` だ。
- 検証の理由は入力欄の `aria-describedby`、操作の失敗は `role="alert"`、件数の変化は `role="status"` (`polite`) を使う。
- 色の組: 文字に使う組のうち、`elevated` の上の `fg` と `fg-muted` (チップ、候補)、`bg` の上の `fg` (ダイアログのシノニムのチップ)、`bg` の上の `danger` (動画ページと管理ページの本体の理由と失敗の行) は、すでに `tokens.test.ts` の `pairs` にある。`elevated` の上の `danger` は `pairs` にない (計算で約 5.9 で、4.5 を満たす)。これは選択バーのポップオーバーと管理ページのダイアログ (`ModalFrame` は `bg-elevated`) の中の理由と失敗の行に使う。この選択バーの組を `pairs` に加える。絞り込み中のタグの `accent-soft` の上の `link` は、今の `Chip` のアクセントと同じ組だ。`accent-soft` は半透明なので `pairs` の外にある (`tokens.test.ts` は 6 桁の 16 進の値だけを読む)。新しいトークンは加えない。
