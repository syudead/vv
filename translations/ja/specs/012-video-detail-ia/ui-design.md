# UI 設計: 動画詳細画面の情報構造 {#ui-design-information-architecture-of-the-video-detail-screen}

**機能**: [親 Issue #171](https://github.com/syudead/vv/issues/171)

出典: 視覚的な規則は、[ライブラリ UI: 見た目の規則と一覧の構造](../../docs/design-docs/library-ui.md)と `@theme` ([`web/src/index.css`](../../web/src/index.css)) に従う。この文書は、動画詳細画面 (`/videos/:id`) がそれらに**加えるもの**と**変えるもの**だけを定める。

- 色、角丸、影のトークンは新しく加えない。
- コンポーネントは `web/src/ui/` にある既存のもの (`Button`、`IconButton`、`Skeleton`、`Tooltip`、`Popover`) を使う。

## 画面の範囲 {#screen-boundary}

- プレーヤー画面は以前と同じく `AppShell` の外に置く (ARCHITECTURE.md「Web layer」)。一覧のトップバー (☰、更新) はなく、代わりに独自の見出し帯を持つ (「動画ヘッダー」)。一覧の上に重ね、× で閉じる画面体験は変わらない。
- 画面は見出し帯、プレーヤー、タイトルとタグ、ファイル情報 (「動画の情報」)、関連動画で構成する (親 Issue の要件 1)。
- 次のものは描画しない (要件 4、5)。
  - チップ
  - タイトルの下の要約行
  - タイトルの近くにある大きな操作ボタン (`ファイルを開く` と `パスをコピー` は情報行の右端に小さなアイコンとして残す)
  - タブ
  - 枠またはカードで囲んだ詳細領域
- 次の既存コンポーネントを置き換える。
  - 古い `VideoHeader` と `FileDetails`: タイトルと情報行に置き換える (現在の `VideoHeader` は別のものである見出し帯だ)。
  - プレーヤーの下の赤い帯と `Blocked`: プレーヤー内の状態表示に置き換える。

## レイアウトとレスポンシブ動作 {#layout-and-responsive-behaviour}

Tailwind の標準ブレークポイントだけを使い、切り替えは CSS だけで行う (library-ui.md 4)。

### `lg` (1024px) 以上: 2 列 {#lg-1024px-and-up-two-columns}

- 見出し帯 (高さ `h-navbar`) をページの上端に置き、その下を 2 列にする。
- 列の領域は左右に `px-6`、上に `pt-6` を持つ。下端では左列が `pb-6`、関連動画の一覧も `pb-6` を持つ。列間は `gap-6` だ。
- 左列 (`minmax(0, 1fr)`) は上から次の順に置く。
  - プレーヤー
  - 作成中の行 (ある場合)
  - タイトルとタグ
  - ファイル情報行と技術情報行
- 右列の幅は `lg` で `w-80`、`xl` 以上で `w-96` だ。関連動画の見出しと、関連動画の縦の一覧を置く。
- 右列の上端はプレーヤーの上端にそろえる。
- プレーヤーは `rounded-lg`、`overflow-hidden`、`bg-navbar` だ。既存の `max-w-[calc(max(100dvh-17rem,15rem)*16/9)]` で、16:9 の動画が画面の高さに収まる幅に制限する (16:9 より横長の動画は自身の比率で収まる)。この高さは左列で見出し帯 (`3.25rem`)、列の上下の余白、タイトルとタグ、2 つの情報行の場所を残すため、通常は左列がスクロールしない (`lg` 未満ではページ全体がスクロールするので `12.25rem` のままにする)。短いウィンドウでプレーヤーが消えないよう、高さの項は `15rem` を下回らない (その場合、はみ出た部分は左列内でスクロールする)。左列の下の余白は `pb-6` だ。この制限で列より狭くなったプレーヤーは、タイトルにそろえて左寄せにする (`lg:ml-0`)。高さは動画の縦横比に従い (解像度が不明な間は 16:9、極端な比率は 9:16–21:9 に制限する)、画面に収まる高さまで伸びる。縦長の動画は左右に余白を持たせて枠の中央に表示し、前後のハンドルとコントロールバーの位置と幅は横長の動画と同じにする。
- 左列の要素は `gap-5` で間隔を空ける (要件 `余白のリズム`)。区切り線や枠は使わない。

### `lg` 未満: 縦積み {#below-lg-stacked}

- 見出し帯はページの上端に固定する (`sticky top-0`)。スクロール中も × とロゴに手が届く。
- プレーヤーは見出し帯の下で左右いっぱいに置く (`rounded-none`、左右の余白なし)。プレーヤーに × は重ねない。
- その下の本文は `px-4` (`sm` 以上では `px-6`) で、次の順に置く。
  - 作成中の行
  - タイトルとタグ
  - ファイル情報行と技術情報行
  - 関連動画
- 360px と 768px のどちらでも横スクロールは生じない (受け入れ条件 2)。

## 階層と文字組み {#hierarchy-and-typography}

強い順に、プレーヤー > タイトル > 関連動画 > ファイル情報 > 技術情報とする (要件 `視覚的階層`)。

| 要素 | スタイル |
| --- | --- |
| タイトル | `h1`。`text-xl` (`sm` 以上で `text-2xl`)、`font-semibold`、`text-fg`、`leading-snug`。区切りのないファイル名も折り返す (`[overflow-wrap:anywhere]`)。画面で最も大きい文字 |
| ファイル情報 | `text-sm`、`text-fg`、`tabular-nums`。各値の前に `size-4`、`text-fg-subtle` のアイコン。見える文字ラベルはない |
| 技術情報 | `text-xs`、`uppercase`、`tracking-wider`、`text-fg-muted`、`tabular-nums`。英語なので `lang="en"`。コーデックと形式は大文字 (`H.264`、`AAC`、`MKV`) |
| パンくず | `text-sm`。途中の部分は `text-fg-muted`、最後の部分 (動画を収めるフォルダ) は `font-medium`、`text-fg` |
| 関連動画の見出し | `h2`。`text-sm`、`font-semibold`、`text-fg` |
| 関連動画のタイトル | `text-sm`、`font-medium`、`text-fg`、2 行で切り詰める (`line-clamp-2`) |

## 動画の情報 {#video-facts}

タイトルとタグの下に 2 行を置く (`gap-3`)。区切り線、枠、ラベルはない。

- **ファイル情報行**: `ul` (アクセシブルな名前 `ファイルの情報`) に次の順で置く。
  - 長さ (lucide `Clock`)。長さが不明な間 (たとえば読み取り前) は項目を省く。
  - サイズ (`HardDrive`)。
  - 追加日 (`CalendarPlus`)。日付だけ (`2026/09/20`)。
  - 各項目はアイコンと値の組 (`gap-1.5`) で、項目間は `gap-x-4` (`sm` 以上で `gap-x-5`) とする。幅が足りなくなると折り返す。
  - アイコンは `aria-hidden` とし、代わりに視覚的に隠した `長さ`、`サイズ`、`追加日` を値の前に置く。`title` にも同じ名前を持たせる。
  - 最後に視聴した時刻は表示しない (依頼者の決定)。
- **操作**: 情報行の右端に 2 つの `IconButton` (`size="sm"`) を置く (`text-fg-muted`、ホバー時は `text-fg`)。
  - `ファイルを開く` (`ExternalLink`): ファイルを開ける場合 (`location.openable`) にだけ表示する。押すと `POST /api/videos/{id}/open` を送る。
  - `パスをコピー` (`Copy`): 場所の絶対パスをクリップボードに書き込み、トーストで `パスをコピーしました` を伝える (失敗時は `パスをコピーできませんでした`)。`navigator.clipboard` は安全な接続 (HTTPS、localhost) でだけ使えるため、LAN アドレスでページを開いた場合や書き込みが拒否された場合は、隠した入力欄を選択してコピーする方法に切り替える。
  - 場所 (`location`) がなければ、どちらも表示しない。
- **技術情報行**: `ul` (アクセシブルな名前 `技術情報`) に、解像度、コンテナ、動画、音声の順で値だけを並べる。項目は縦の `border-l border-border-strong` の線と `px-2.5` で区切る。すべての項目に線と余白を付け、一覧全体をその幅だけ左へずらして外側の要素 (`overflow-hidden`) で切り取るため、折り返した行の先頭には線も余白も残らない。不明な値 (音声がない場合など) は項目ごと省く。

  | 状況 | 技術情報行 |
  | --- | --- |
  | 読み取り前 | `技術情報を読み取り中` (`text-fg-muted`) |
  | 読み取り失敗 | `技術情報を読み取れませんでした` (`text-warning`) |

- ファイルを開く操作が失敗したとき (409 `file_missing` など)、情報行のすぐ下 (技術情報行の上) に 1 行を表示する。
  - `text-sm text-danger`。先頭に `AlertCircle` (`size-4`)、`role="alert"`。
  - `file_missing` なら `開けませんでした: ファイルが見つかりません`、それ以外なら `開けませんでした` と表示する。
  - 次の開く操作、または別の動画への移動で消える。
  - 帯、トースト、ダイアログは使わない (要件 `要求を満たしたことにならない変更`)。

## 関連動画 {#related-videos}

- 見出しは `h2` の `関連動画` だ。ここには × を置かない (見出し帯にある)。
- 関連動画が 0 件なら、`h2` も一覧も表示しない (境界事例)。
- 各項目は 1 つのリンクで、行全体をクリックできる。
  - 左にサムネイル (`w-40`、16:9、`rounded-md`、`overflow-hidden`、`bg-surface`)、右にタイトル (`gap-3`) を置く。
  - サムネイルがなければ `VideoCard` と同じ代替表示を使う。
  - 長さはサムネイルの右下に置く (`bg-overlay`、`text-xs`、`text-fg`、`tabular-nums`、`rounded-sm`、`px-1`)。
  - 一部を視聴した動画だけ、サムネイルの下端に `accent` の進捗バー (高さ 3px、比率 `watchedRatio`) を表示する (要件 15)。
  - 追加日、`次に再生`、理由の文は表示しない (要件 15)。
- 項目間は `gap-3` とする。ホバー時は行に `bg-hover-wash` を付ける (行の外側に `p-1.5 -m-1.5` と `rounded-lg`)。キーボードフォーカスは共通の `:focus-visible` の輪郭線で示す。
- マウスを載せると、一覧のカードと同じ規則 (library-ui.md のホバープレビュー) で一覧用プレビューを再生する。400ms 後に消音、ループで再生し、マウスを外すと止める。タッチ、ペン、プレビューが未完成の動画では再生しない。
- `lg` 以上ではページを画面の高さに固定し (`h-dvh`、ページ自体はスクロールしない)、左右の列をそれぞれ内部でスクロールさせる。右列は見出し行を上端に保ち、関連動画の一覧だけを動かす。これにより、ページと列が同時にスクロールするのを防ぐ。`lg` 未満ではページ全体を一体としてスクロールさせる。
- 両列にスクロールバーを常時表示すると煩雑なので、`web/src/index.css` で両方とも常にスクロール可能とし、次のようにする。
  - 左列は `scrollbar-none` を使い、スクロールバーを描かない。通常はプレーヤーの高さ制限ではみ出さない。タイトルの折り返しや作成中の行で少しはみ出しても、動画の上にマウスを置いたままでバーが表示され続けることはない。
  - 関連動画の一覧は `scrollbar-on-hover` を使う。細く、普段は透明で、一覧にマウスがある間かフォーカスがある間だけ表示する。
- 状態:

  | 状態 | 画面の表示 |
  | --- | --- |
  | 読み込み中 | 6 行のスケルトン (サムネイルと 2 行の `Skeleton`) |
  | 読み込み失敗 | 見出しの下に `text-sm text-fg-muted` の `関連動画を取得できませんでした` と `ghost` の `再試行` |

## 動画ヘッダー {#video-header}

- ページ上端の帯は一覧のトップバーと同じ高さ (`h-navbar`) で、`border-b border-border`、`bg-bg/90`、`backdrop-blur-md` を使う。どの幅でも `sticky top-0` で上端にとどまる。
- 左から右へ次の順に置く。
  - ロゴ (`●` と `vv`): `/` (ホーム) へのリンクで、アクセシブルな名前は `ホーム`。
  - パンくず (`nav`、アクセシブルな名前 `フォルダ`): 登録フォルダの表示名から動画を収めるフォルダまでの部分を、`ChevronRight` (`size-3.5`、`text-fg-subtle`) で区切る。
    - 各部分は対応するフォルダ画面 (`/folders/{rootId}/…`) へのリンクだ。現在の画面は動画なので、最後の部分もリンクにする。
    - 値は `GET /api/videos/{id}` の `folder` (`rootId`、`path`、`rootName`) から取る。`folder` または `rootName` がなければ (登録が削除された直後など)、パンくず全体を省く。
    - `md` 未満では最後の部分だけを残し、途中の部分を `…` にまとめる。切り替えは CSS だけで行う (library-ui.md 4)。
    - 動画のタイトルは帯に表示しない (すぐ下の `h1` と重複するため)。
  - 右端の × (lucide `X`、`size-5`): アクセシブルな名前が `閉じる` の `IconButton`。
- × はこの帯だけに置き、プレーヤーの上や関連動画の見出しには置かない。
- プレーヤー画面のトースト (`パスをコピー` の結果、スキャンの通知) は一時的に帯の中央に重なり、パンくずを隠すことがある。左右にそれぞれ `4rem` を残すため、× は決して覆わない。
- × は `state.from` の一覧に戻る。Esc も同じだ。

## プレーヤー {#player}

### コントロールバー {#control-bar}

コントロールバーは既存の `.vv-video-player` の規則 (`index.css`) の見た目を保ち、配置だけを変える (要件 6)。

- 左から右へ次の順に置く。
  - 最初に戻る (lucide `RotateCcw`。再生・一時停止は変えずに位置を 0 にする。キー 0)
  - 再生・一時停止
  - 音量 (ミュート)
  - 現在時刻 / 長さ
  - 右寄せのスペーサー
  - `変換して再生中` (変換しながら再生している間だけ)
  - 再生速度
  - ピクチャーインピクチャー
  - 全画面表示
- 秒数単位のシーク (10 秒戻る・進む) は、ボタンにもキー (←/→) にもない。
- 前後の動画はコントロールバーには置かず、プレーヤーの左右端に置く (後述の「前後の矢印」)。
- 進捗バーは以前と同じくコントロールバーの上に置き、シーク用サムネイルも同様だ。
- 残り時間は表示しない (要件 5)。
- 音量とミュートはブラウザーに保存し、次の動画に引き継ぐ。保存値が壊れているかブラウザーの保存領域を使えない場合は、音量 100%、ミュートなしで再生する。
- 速度の選択肢は 0.5、0.75、1、1.25、1.5、2 だ。
- キーボードショートカットのあるボタンには `aria-keyshortcuts` を付け、ホバー時の説明にもキーを含める (`一時停止（Space）` など)。
- `変換して再生中` は次のように表示する。
  - lucide `Info` (`size-3.5`) と `text-xs text-fg-muted` の文字。
  - `web/src/ui/Popover.tsx` の起点 (`button`) とする。クリック、タップ、Enter で小さな吹き出しを開き、理由 `ブラウザがそのまま再生できない形式のため、変換しながら再生しています。シークに数秒かかります。` を表示する。
    - ホバーでだけ開くツールチップにはしない。タッチやキーボードの利用者が理由に到達できなくなるためだ (要件 10)。
  - ほかのコントロールバーのボタンより控えめに見せる (枠も面もなく、文字色は `fg-muted`)。

### 前後の矢印 {#neighbor-arrows}

- 前後の動画へ移動するハンドルは、プレーヤーの左右の端に接して置く。左 (lucide `ChevronLeft`) は同じフォルダの自然順で前の動画、右 (`ChevronRight`) は次の動画へ進む。
- 動画を隠さないよう幅を狭くし、押しやすいよう高さを持たせる。

  | 幅 | ハンドルの大きさ |
  | --- | --- |
  | `sm` 以上 | 幅 `w-8`、高さはプレーヤーの 50% (最小 `min-h-24`) |
  | `sm` 未満 | 幅 `w-7`、高さはプレーヤーの 55% (最小 `min-h-18`) |

  - コントロールバー (約 3rem) を除いた動画領域の縦中央に置く。
  - 面は `bg-overlay`、ホバー時は `bg-bg`。端に接する側は丸めず、内側だけを `rounded-lg` にする。端に暗いグラデーションは付けない。
- コントロールバーと同じとき、および再生終了中に表示する。隠れている間は押せず、キーボードフォーカスが来ると表示する。
- 関連動画の応答にその側の `prevId` または `nextId` がなければ表示しない (フォルダの先頭や末尾、関連動画の読み込み中や失敗後)。
- ホバー時にはハンドル内のツールチップに `前の動画: {題名}` / `次の動画: {題名}` を表示し、アクセシブルな名前も同じにする。移動先が関連動画の一覧になく、題名が不明なら `前の動画` / `次の動画` だけにする。
- 再生中または再生終了後に移動すると、移動先で再生を始める。一時停止中に移動した場合は始めない。戻り先 (`state.from`) は引き継ぐ。

### タッチ操作 {#touch-controls}

- 粗いポインター (`pointer: coarse`) の機器では、動画をタップすると再生と一時停止を切り替える。コントロールバーからも操作できる。中央の video.js の大きな再生ボタンは CSS で隠し、動画の領域を遮らない。
- コントロールバーには秒数単位でシークするボタンを置かない。

### 重ねるレイヤー {#overlay-layer}

プレーヤーに重ねるレイヤーは 1 つのコンテナ内に積む。上から次の順だ。

1. 状態表示
2. 再生終了

一度に表示するのは 1 つだけだ。

状態表示はすべてプレーヤーの領域内に収める (要件 10)。

- 作成中の行 (プレーヤーのすぐ下) だけは領域の外に置く。
- 内容が動画の縦横比に収まらない幅 (360px での段階表示など) では、内容に合わせて領域を広げる。動画の縦横比は最小値として保つ。
- 再生失敗と再生終了のレイヤーは、重なり順で video.js のコントロールバーより**下**に置く。暗くするのは動画だけで、コントロールバーは見えて操作できる。
- レイヤーの文字は決して `bg-overlay` の上に直接置かない。`bg-overlay` は半透明で、明るい最終フレームの上では `fg-muted` や `accent` の文字に十分なコントラストがない。文字のブロックは、不透明な `bg-navbar`、`rounded-lg`、`p-5` の面に置く。

| 状態 | 画面の表示 |
| --- | --- |
| 読み込み中 | サムネイルがあれば背景に置き、中央に `LoaderCircle` (`size-7`、`text-accent`、回転) を表示する。視覚的に隠した `読み込み中` を `role="status"` で読み上げる。読み込みが終わるまでコントロールバーは隠す |
| 変換しながら再生中 | 前述の「コントロールバー」を参照。レイヤーはない |
| 再生失敗 | 動画の上に `bg-overlay` を置く。中央の `bg-navbar` の面 (`max-w-md`) に `AlertCircle` (`size-8`、`text-danger`)、`h2` の `再生できませんでした` (`text-lg font-semibold`)、理由 (`text-sm text-fg-muted`)、`secondary` の `{m:ss} からもう一度試す` (`RotateCcw`) を積む。`role="alert"` |
| スキャン中 (読み取り前) | 後述の「処理の段階」を参照 |
| 読み取り失敗 | `bg-navbar` の面 (`max-w-lg`) の中央に、`AlertTriangle` (`size-8`、`text-warning`)、`h2` の `この動画を読み取れませんでした`、説明 `ファイルが壊れているか、途中までしか書き込まれていない可能性があります。` (`text-sm text-fg-muted`)、生の理由、操作を積む。生の理由には `bg-field`、`border border-border`、`rounded-md`、`font-mono text-xs text-fg`、`break-all` を使い、3 行を超えた部分は内部でスクロールさせる。操作は `secondary` の `もう一度読み取る` (`RefreshCw`) と、ファイルを開ける場合に限り `secondary` の `ファイルを開く` (`FolderOpen`) だ。送信中はボタンを無効にし、アイコンを回転する `LoaderCircle` に変える。202 または 409 `probe_not_failed` では動画を再取得し、画面を段階表示に移す (409 は別のタブまたは二重押しですでに再試行が始まったことを意味する)。ほかの失敗では、ボタンの下に `text-sm text-danger` の `読み取りを始められませんでした` を表示し、ボタンを再び押せるようにする。`role="alert"` |
| 動画がない (404) | `bg-navbar` の面の中央に `AlertCircle` (`text-fg-muted`)、`h2` の `この動画は開けません`、`ライブラリから外れたか、ファイルが無くなりました。` を置く。`role="alert"` のため、再取得や再生でこの表示に切り替わると読み上げられる。戻る操作は × に任せ、ボタンは加えない |

### 処理の段階 {#processing-stages}

スキャン中 (`probeState=pending`) の面の見た目を定める (要件 12)。

- 面は `bg-navbar` で、中央に左寄せのブロック (`max-w-sm`) を置く。
- ブロックには上から次の順に置く。
  - `h2` の `再生の準備をしています` (`text-lg font-semibold`)
  - 説明 `動画の情報を読み取っています。終わるとこの画面のまま再生できるようになります。` (`text-sm text-fg-muted`)
  - 段階の `ol`
  - 注記 `再生できるのは『動画情報の読み取り』が終わってからです。残りは再生中に作られます。` (`text-xs text-fg-muted`)
- 5 つの段階は次の固定順とする。

  | 段階 | 表示 | 導出元 |
  | --- | --- | --- |
  | ファイルの検出 | `ファイルの検出` | 常に `完了`: 動画の行が存在するため、検出は終わっている |
  | 読み取り | `動画情報の読み取り` | `probeState` |
  | サムネイル | `サムネイル` | `thumbnailState` |
  | シーク用プレビュー | `シーク用プレビュー` | `seekThumbnailState` |
  | 一覧用プレビュー | `一覧用プレビュー` | `previewState` |

- 各行にはアイコン、名前 (`text-sm`)、右端の状態の文字 (`text-xs`) を表示する。

| 行の状態 | アイコン | 名前 | 状態の文字 |
| --- | --- | --- | --- |
| 完了 | `CircleCheck` (`text-success`) | `text-fg` | `text-fg-muted` の `完了` |
| 処理中 | `LoaderCircle` (`text-accent`、回転) | `text-fg font-medium` | `text-accent` の `処理中` |
| 待機中 | `Circle` (`text-fg-muted`) | `text-fg-muted` | `text-fg-muted` の `待機中` |
| 作成失敗 | `AlertCircle` (`text-warning`) | `text-fg-muted` | `text-fg-muted` の `作成できませんでした` |

- 行間は `gap-3`、アイコンと名前の間は `gap-2.5` とする。
- `sm` 未満では説明と注記を省き、行間を `gap-1.5` に詰める。
- ブロックは `role="status"` (`aria-live="polite"`) なので、段階が進んだときだけ読み上げる。内容が変わらない 2 秒ごとの再取得では読み直さない。

### 作成中の行 {#creating-line}

読み取りが終わり、まだ何かを作成している場合に限り、プレーヤーのすぐ下に 1 行を表示する (要件 11)。

- 「作成中」とは、サムネイル、シーク用プレビュー、一覧用プレビューのいずれかが `pending` であることを指す。
- スタイルは `flex items-center gap-2`、`text-xs text-fg-muted` で、先頭に `LoaderCircle` (`size-3.5`、`text-accent`、回転) を置く。
- 文は `{作成中のもの}を作成中 · 再生はできます` とする。作成中のものは、上記の段階名を `と` でつなぐ (例: `シーク用プレビューと一覧用プレビューを作成中 · 再生はできます`)。件数や割合は表示しない。
- `role="status"`。`pending` がなくなると、行全体が消える (`failed` だけが残る場合も同じ)。

### 再生終了 {#ended}

再生が終わると、このレイヤーを表示する (要件 14)。

- 動画の上に `bg-overlay` を置く。コントロールバーはその上に表示し続ける (もう一度見る操作にも使える)。
- **次の動画がある場合**、中央の `bg-navbar` の面 (`max-w-lg`) に次のものを積む。
  - ラベル `次の動画` (`text-xs font-semibold text-accent`)
  - 次の動画へのリンク: サムネイル (`w-56`、16:9、`rounded-md`、長さのタグ付き) とタイトル (`text-base font-semibold`、2 行で切り詰める) を横に並べる
  - 操作: `primary` の `次を再生` (`Play`) と `secondary` の `もう一度見る` (`RotateCcw`)
  - `sm` 未満ではサムネイルを省き、タイトルと操作だけを表示する。
- **次の動画がない場合**、中央に `secondary` の `もう一度見る` だけを置き、ラベルは付けない。
- 自動再生もカウントダウンもない。
- レイヤーが現れたら、視覚的に隠した `再生が終わりました` を `role="status"` で読み上げる。
  - フォーカスがプレーヤー内にあった場合に限り、`次を再生` (次がない場合は `もう一度見る`) に移す。
  - プレーヤーの外 (関連動画など) にあるフォーカスは奪わない。

## 操作の詳細 {#interaction-details}

- **キーボード**: ←/→ による秒数単位のシークはない。
  - 速度メニューを開いている間の Esc は、メニューだけを閉じる。
  - 全画面表示中の Esc は、全画面表示だけを終了する。
- **Tab の順序**: すべての幅で DOM の順序に従う。見出し帯 (ロゴ → パンくず → ×) → プレーヤー (状態または再生終了のレイヤー内の操作 → コントロールバー) → タグ → 情報行の操作 → 各関連動画。
- **動きを減らす設定** (`prefers-reduced-motion: reduce`): 回転 (`LoaderCircle`) と、レイヤーの出入りの `animate-fade-in` を止める。状態の見た目は変わらない (library-ui.md 4)。

## アクセシビリティ {#accessibility}

- アクセシブルな名前:
  - × は `閉じる`
  - コントロールバーの `最初に戻る`
  - 両端のハンドルは `前の動画: {題名}` と `次の動画: {題名}`
  - ロゴは `ホーム`、パンくずの `nav` は `フォルダ`
  - 情報行の `ファイルを開く` と `パスをコピー`
  - ファイル情報と技術情報の `ul` は `ファイルの情報` と `技術情報`
- ファイル情報の各値の前に、視覚的に隠した名前 (`長さ` など) を置く。技術情報行には `lang="en"` を付ける。
- 読み上げ方:

  | ロール | 要素 |
  | --- | --- |
  | 状態 (`status`) | 段階表示、作成中の行、読み込み中、再生終了 |
  | 警告 (`alert`) | 再生失敗、読み取り失敗、動画がない (404)、ファイルを開く操作の失敗行 |

- タイトルは `h1` で、`document.title` は以前と同じ `{題名} - vv` のままにする。
- 色とコントラストの組:
  - 新しい組は `navbar` 上の `fg-muted` だけだ (段階表示、読み取り失敗、再生失敗の説明)。実装 PR では `tokens.test.ts` の `pairs` に追加する。
  - レイヤー内の文字はすべて不透明な `bg-navbar` の上に置く (「重ねるレイヤー」)。半透明の `bg-overlay` 上の文字は `pairs` で確認できないため、そこに文字は置かない。
  - ほかの組 (`bg` 上の `fg` と `fg-muted`、`bg` 上の `warning`、`navbar` 上の `fg`、`accent`、`success`) はすでに含まれている。
  - アイコンだけに使う色 (`navbar` 上の `danger` や `warning` など) は文字ではないため、組に追加しない。
