# 製品仕様 {#product-specifications}

機能の仕様は親 GitHub Issue だ。この一覧にはもう何も追加しない。

SDD の成果物は feature ブランチ上の一時的な作業記録だ。統合前に、残すべき決定を `docs/design-docs/` に移し、検証後に成果物とその翻訳を削除する。永続的な文書とコードは、設計文書、API スキーマ、テストを参照し、`specs/` の完了した Plan、調査、UI 設計、契約は決して参照しない。Git の履歴にそれらは残る。
