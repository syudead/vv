# 実行計画: コンパクトな動画ライブラリ UI

- ステータス: 完了
- 対象: `web/src/` の一覧画面、文書、テスト

## 目的

StashApp / Fireshare に近い密度で、動画を素早く見渡して選べる一覧にする。検索、並び順、
密度、取り込み、再生、一覧復元の既存動作は維持する。

## 実施内容

1. ロゴとページ見出しを外し、展開 / アイコンのみを切り替えられるサイドバーにした。
2. 件数、検索、絞り込み、並び順、密度、更新をコンパクトなツールバーへまとめた。狭幅では
   3行に分け、操作を縮小しない。
3. カードから解像度とコンテナを除き、サムネイル、題名、尺、再生状態へ絞った。
4. ホバー時に現れ、1件選択後は全件に表示されるチェックボックスを追加した。タッチ端末と
   キーボード操作ではホバーなしでも選択を開始できる。
5. 選択時は画面下部の固定バーへ件数と選択解除だけを表示し、通常ツールバーを動かさない。
   未実装の一括操作は追加しなかった。
6. 再生状態の絞り込み、密度切替の左右キー操作、更新中表示を実装した。

## 検証結果

- `npm run build`: 成功
- `npm test`: 17ファイル、156件すべて成功
- 実ブラウザ: 360pxと1440px、展開・縮小サイドバー、3段階の密度、検索0件、絞り込み、
  1件選択、キーボードフォーカスを確認。360pxで横溢れなし
