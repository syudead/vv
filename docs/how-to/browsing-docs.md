# 文書を閲覧サイトで読む

リポジトリの Markdown（`docs/`、`specs/`、`.agents/` など、版管理下の全ての
`.md`）を、サイドバーの一覧・全文検索・目次つきのサイトとして読む。

## 手元で開く

```bash
mise exec --command "task docs"
```

<http://127.0.0.1:6060/> を開く。要求のたびに文書を読み直すので、文書を直して
ブラウザを再読み込みすれば反映される。まだ `git add` していない新しい文書も
一覧に出る（`.gitignore` で無視されたファイルは出ない）。

- 待ち受けるアドレスは `task docs -- -addr <host>:<port>` で変えられる。既定は
  手元（127.0.0.1）だけで、認証はない。手元の外から届くアドレスにすると、届く人は
  誰でも全ての文書を読めるので、信頼できるネットワークでだけ使う。
- 文書に書いた生の HTML は出さない（未追跡の文書に書かれたスクリプトを動かさない
  ため）。
- `/` キーで検索欄へ移る。空白で区切った語を全て含む文書を、題とパスに当たる
  ものから順に並べる。
- 文書どうしのリンクと見出しへの anchor（`#r-3-…` のような日本語の見出しも）は
  GitHub と同じ規則で通る。画像はサイトから出し、ソースや設定ファイルへの
  リンクは GitHub の表示へ向ける。

## 静的な HTML に書き出す

```bash
mise exec --command "task docs-build"
```

`build/docs/` に書き出す（版管理の外）。`task docs-build -- -out <dir>` で書き出し先を
変えられる。既存のディレクトリを置き換えるのは、空のときか前回の書き出し（印の
`.docsite-export` がある）のときだけで、それ以外のディレクトリには手を触れずに止まる。相対パスだけで組むので、
`build/docs/index.html` をブラウザで直接開いても一覧と検索が使える。どこかへ
置く場合もこのディレクトリをそのまま配れば足りる。

## 仕組み

実体は `scripts/docsite` の Go プログラムで、Markdown の描画に
[goldmark](https://github.com/yuin/goldmark)（GFM の表・タスクリスト・脚注）を
使う。見た目と振る舞いは `scripts/docsite/assets/` にある。
