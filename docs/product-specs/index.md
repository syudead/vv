# Product specifications

A feature's specification is its parent GitHub Issue. Nothing is added to this
list any more.

`specs/001-008` held frozen records of features already built. They were removed
because the implementation and its tests are the source of truth for what the
system does today, and the frozen text had drifted from both. Git history still
carries them if an audit needs them.
