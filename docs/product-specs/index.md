# Product specifications

A feature's specification is its parent GitHub Issue. Nothing is added to this
list any more.

SDD artifacts are temporary working records on a feature branch. Before
integration, lasting decisions go into `docs/design-docs/` and the artifacts
and their translations are deleted after validation. Permanent documentation
and code reference design docs, API schemas and tests, never completed plans,
research, UI designs or contracts under `specs/`. Git history retains them.
