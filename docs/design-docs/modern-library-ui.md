# コンパクトな動画ライブラリ UI

- ステータス: 採用
- スコープ: 動画一覧の情報階層、選択操作、サイドバー

## 判断

一覧は StashApp / Fireshare に近い、管理画面として密度の高い構成にする。独立した
ヘッダーやページ見出しは置かず、左のサイドバー、上部のコンパクトなツールバー、固定幅に
近いサムネイルグリッドで構成する。カード幅は密度ごとに最小・推奨・最大を持ち、画面の
余白を埋めるためだけに無制限に拡大しない。ブランド領域はロゴが決まるまで空け、仮のアイコンや
製品名を表示しない。

サイドバーはアイコンと文字を表示する展開状態と、アイコンだけの折りたたみ状態を持つ。
切り替えにはパネルの伸縮を表すアイコンを使い、状態は端末に保存する。折りたたんだときは
カードを拡大せず、グリッドが使える横幅を増やす。現在使えるライブラリに加え、画面構成を
示す「最近追加」「視聴途中」は非対話要素として表示する。

カードの一次情報はサムネイル、題名、再生時間、再生進捗だけとする。解像度、コンテナ、
ファイルサイズは一覧へ出さない。カード全体を囲う重い外枠は使わず、サムネイルと一行の
題名を短い間隔で並べる。

選択チェックは通常隠し、カードをポイントしたときだけ表示する。1件でも選択されたら全件の
チェックを表示し、画面下部に件数と「選択解除」を持つ固定バーを出す。通常のツールバーは
選択の前後で位置や高さを変えない。選択を起点にした一括
操作は、実体のある機能が追加されるまで設けない。

操作状態は部品ごとにばらばらにせず、通常、hover、focus-visible、active、selected、
disabledを明確に分ける。キーボードフォーカスはアクセント色の外側輪郭、hoverは境界と
背景の小さな変化、activeは沈んだ背景で示す。検索と選択欄は内側のinputではなく外枠に
フォーカスを出し、二重輪郭を避ける。表示密度は選択中のボタンだけをTab順に置き、左右キー
でも切り替えられる。カードの再生リンクと選択チェックは別々のフォーカスを持つ。
hoverできない端末では選択チェックを常時表示し、キーボードからも最初の選択を開始できる。

配色は暗いチャコールを基調に、選択と進捗へミント、警告へアンバーを使う。カード半径は
8px 以下とし、ページ区画を浮いたカードにはしない。
