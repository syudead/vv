# Landing page

`index.html` is the static landing page for VVMDM: one HTML file with inline
CSS, the library screenshot `library.webp` and the icon `favicon.svg`. It has
no build step and no script; open `index.html` in a browser to view it.

The page is not deployed yet, and these parts are placeholders:

| Part | Placeholder | Replace with |
| --- | --- | --- |
| Demo section | `[DEMO USERNAME]`, `[DEMO PASSWORD]` | The demo account |
| "Open the live demo" links | `#demo` | The demo URL |
| `library.webp` | A screenshot of generated sample videos | A screenshot of the demo library |

The Windows and Docker cards use the page's own icons, not the Windows or
Docker logos: both trademark guidelines require permission to show those logos,
and the names in text are enough to identify the platform.
