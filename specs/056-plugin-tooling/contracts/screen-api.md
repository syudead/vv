# Contract: Screen API changes

Source of truth: [api/openapi.yaml](../../../api/openapi.yaml); Go and
TypeScript are generated by `task generate`. Every operation below is owner
only, as in [049 screen-api.md](../../049-work-info-plugins/contracts/screen-api.md).
The external API and MCP do not change.

## `WorkInfoPluginSetting`

Three optional fields join the entry
([R-3](../research.md#r-3-a-setting-declares-default-and-options-the-stored-value-or-the-default-is-what-the-run-receives)).

| Field | Type | Meaning |
| --- | --- | --- |
| `default` | string, optional | The manifest's default |
| `options` | string array, optional | The manifest's options, in its order |
| `staleValue` | string, optional | A stored value that is not one of the current options; present only then. The run receives the default instead |

`set` and `value` keep their meaning of
[049](../../049-work-info-plugins/contracts/screen-api.md): whether a value is
stored and, for a non-secret setting, that value. A stale value is still
stored, so its setting has `set: true`, the value in `value`, and the same
text in `staleValue`; a secret setting has no options, so it is never stale.

## `WorkInfoPlugin`

## `GET /api/work-info-plugins/{id}/last-run`

Returns the plugin's last run's output.

**Response**: `200` with `{"run": WorkInfoPluginRun}`, or `{}` when no run
of the current module is kept.

| `WorkInfoPluginRun` field | Type | Meaning |
| --- | --- | --- |
| `ranAt` | integer | Unix seconds |
| `operation` | `WorkInfoOperation` | The operation that ran |
| `failure` | string, optional | The run failure code of [049 Run failures](../../049-work-info-plugins/contracts/screen-api.md#run-failures) when the run failed; absent for a successful run |
| `stderr` | string | The kept standard error with secret values masked; empty when the plugin wrote nothing |
| `truncated` | boolean | Whether output after 64 KiB was dropped |

| Status | `code` | When |
| --- | --- | --- |
| 404 | `not_found` | No such plugin |

## `GET` and `PUT /api/settings/plugin-proxy`

Reads and writes the proxy the plugin runs use
([R-4](../research.md#r-4-the-proxy-is-one-url-in-settings-read-on-each-run-and-passed-to-the-runtime-as-a-run-option)).
Unlike `/api/settings/network`, the route answers on every build.

| Field | In | Type | Required | Meaning |
| --- | --- | --- | --- | --- |
| `url` | body | string | Yes | `http`, `https` or `socks5`, a host, an optional port and optional user information; no path or query; at most 2048 characters. `""` means no proxy |

**Response**: `200` with `{"url": "<the saved value>"}`; `GET` answers `""`
when nothing is saved.

| Status | `code` | When |
| --- | --- | --- |
| 400 | `invalid_request` | `url` is missing or breaks the rule |

The next run uses the saved value; a run in progress finishes with the value
it started with.

## `POST /api/videos/{id}/work-info-fetches/{fetchId}/apply`

The request gains `tags`
([R-7](../research.md#r-7-the-apply-takes-the-selected-tag-names-and-a-tag-already-on-the-video-is-not-selectable)).

| Field | In | Type | Required | Meaning |
| --- | --- | --- | --- | --- |
| `tags` | body | string array | No | The fetched names to attach when `fields` holds `tags`; a non-empty subset of the result's `tags`, spelled as the result returned them. Absent means every fetched tag, as before |

| Status | `code` | When |
| --- | --- | --- |
| 400 | `invalid_request` | `tags` is empty, holds a name the result does not, or is present while `fields` lacks `tags` |

`skippedTags` reports only the selected names.

## Run failures

| Status | `code` | `reason` | Change |
| --- | --- | --- | --- |
| 502 | `plugin_failed` | `network_error` | `Error.host` is the proxy's host when the proxy could not be reached, refused the connection or answered `407` ([R-5](../research.md#r-5-through-a-proxy-the-destination-is-checked-by-resolving-its-name-before-each-request-and-redirect)) |
| 502 | `plugin_failed` | `blocked_address` | Also answered when, through a proxy, the destination name resolves to a refused address; `Error.host` is that name |
