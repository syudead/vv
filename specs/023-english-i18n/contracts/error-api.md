# Contract: API error reasons and failure reason codes

Source of truth: [api/openapi.yaml](../../../api/openapi.yaml); Go and
TypeScript are generated by `task generate`. This document describes only what
this feature adds or changes. Existing `code` values, each path's HTTP status,
and machine-readable values such as `state` do not change.

## Every `message` in English

`Error.message` becomes an English sentence read by users and API consumers. It
contains no free text returned by the OS or by external programs. When it
includes user data (paths, names), the data is not translated; only the
surrounding explanation is in English. The `description` becomes "An English
description. The screen displays from `code` and `reason`; this text is the
fallback for API consumers and for unknown codes."

The plain-text failure responses (`http.Error`) in `internal/httpapi/spa.go`,
and the fixed JSON used when `writeJSON` cannot build a response, also become
English.

## `reason`, `limit` and `tagName` on `Error`

`Error` gains the following three optional fields
(`additionalProperties: false` is kept).

| Field | Type | Meaning |
| --- | --- | --- |
| `reason` | string enum (`ErrorReason`) | A sub-reason that distinguishes situations within the same `code`. Returned only in the situations in the table below |
| `limit` | integer | The limit for that reason. Returned only when the table has a value in the `limit` column |
| `tagName` | string | The original name of the tag the request collided with (user data, not translated). Returned only when the table marks `tagName` |

A response without `reason` is the same as today, and the screen shows the
wording for `code`.

| `code` (HTTP) | `reason` | `limit` | Situation (current location) |
| --- | --- | --- | --- |
| `tag_name_taken` (409) | `name_is_tag` | — | The sent name is the original name of an existing tag. Returns `tagName` (`tagNameTakenMessage` in `tags.go`) |
| `tag_name_taken` (409) | `name_is_synonym` | — | The sent name is a synonym of another tag. `tagName` is that tag's original name (same as above) |
| `tag_merge_required` (409) | — | — | The rename target is another tag's name. Returns `tagName` (`tags.go`) |
| `invalid_request` (400) | `username_length` | `domain.MaxUsernameLength` | Username length (`auth.go`) |
| `invalid_request` (400) | `password_length` | `domain.MaxPasswordBytes` | Password length (`auth.go`) |
| `invalid_request` (400) | `tag_name_empty` | — | Empty tag name (`domain.NormalizeTagName`; `tags.go`, `video_tags.go`, and tagging from a folder name in `folder_groups.go`) |
| `invalid_request` (400) | `tag_name_control_characters` | — | Control characters in the tag name (same as above) |
| `invalid_request` (400) | `tag_name_too_long` | `domain.TagNameMaxLength` | Tag name too long (same as above) |
| `invalid_request` (400) | `merge_same_tag` | — | Merge source and target are the same tag (`tags.go`) |
| `invalid_request` (400) | `search_too_long` | `maxQueryLength` | Search term too long (`videos.go`) |
| `invalid_request` (400) | `too_many_tag_filters` | `maxTagFilterCount` | Too many tag filters (`videos.go`) |
| `invalid_request` (400) | `too_many_videos` | `maxVideoTagsIDs` | Zero or too many videos in a bulk action (`video_tags.go`, `visibility.go`) |
| `invalid_request` (400) | `too_many_tags` | `domain.MaxTagBatch` | Zero or too many tags in a bulk tag action, an impact count or a merge (`tags.go`; [036 screen-api.md §1–§3](../../036-tag-admin-scale/contracts/screen-api.md#post-apitagsbatch)). | `not_found` (404) | `not_folder_group` | — | The folder is not a group (`library.go`) |
| `not_found` (404) | `no_scan` | — | No import has run yet (`scans.go`) |
| `not_found` (404) | `directory_not_found` | — | The chosen directory does not exist (`directories.go`) |
| `not_found` (404) | `file_unavailable` | — | The video file cannot be opened (`stream.go`, `transcode.go`) |
| `conflict` (409) | `media_folders_changed` | — | Media folders were changed by another operation (`media_folders.go`) |
| `conflict` (409) | `root_group_not_taggable` | — | The group of a registered folder itself cannot become a tag (`folder_groups.go`) |
| `conflict` (409) | `folder_not_group` | — | The folder is not a group now (`folder_groups.go`) |
| `conflict` (409) | `probe_info_missing` | — | The probe data the seek preview or live transcode needs is missing (`seek_thumbnail.go`, `transcode.go`) |
| `conflict` (409) | `seek_preview_generating` | — | The seek preview is being generated (`seek_thumbnail.go`) |
| `conflict` (409) | `transcode_unavailable` | — | Live transcoding is not possible (`transcode.go`) |
| `forbidden` (403) | `cross_origin` | — | A change that is not same-origin (`media_folders.go`) |
| `forbidden` (403) | `open_not_local` | — | An attempt to open from a PC other than the server (`open.go`) |

Other `invalid_request` and `not_found` responses (sort order, `attempt`,
Content-Type, a missing path, and other values the screen never sends) return
no `reason`.

`limit` is filled from the server's constants; the screen holds no limits of its
own. The colliding tag name that today's Japanese `message` embeds is returned
in `tagName`, and the screen combines it with the sent name into a specific
explanation (the specificity of requirement 6). A failure of
`domain.NormalizeTagName` becomes a domain error that carries a reason instead
of today's string, and `internal/httpapi` maps it to `reason`.

## `Video.probeErrorCode`

`Video` gains an optional `probeErrorCode` (string enum `ProbeErrorCode`). It is
returned only for rows with `probeState = failed` and a stored code. The values
are in the table in
[data-model.md, `videos.probe_error_code`](../data-model.md#videosprobe_error_code). `probeError`
(free text) is still returned as now. Both are omitted from guest responses
(the same treatment as today's `probeError`).

The screen does not display `probeError`. It shows the explanation for
`probeErrorCode` when present, and otherwise (rows from before the upgrade) a
general English summary.

## `Scan.errorCode` and `Scan.errorPath`

`Scan` gains two optional fields.

| Field | Type | Meaning |
| --- | --- | --- |
| `errorCode` | string enum (`ScanErrorCode`) | The reason, when `state = failed` and a code is stored. Values in [data-model.md, `scans.error_code` and `scans.error_path`](../data-model.md#scanserror_code-and-scanserror_path) |
| `errorPath` | string | When the reason is tied to a specific place, its absolute path (the media folder, or the unreadable place under it; user data, not translated) |

`error` (free text) is still returned as now. The screen does not display
`error`; it builds an English explanation from `errorCode` and `errorPath`. A
`failed` without `errorCode` (rows from before the upgrade) shows a general
English summary.
