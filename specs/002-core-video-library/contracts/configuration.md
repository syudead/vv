# 設定の契約（コア機能での差分）

**Feature**: [spec.md](../spec.md) | **Plan**: [plan.md](../plan.md)

001 の[設定契約](../../001-initial-setup/contracts/configuration.md)を引き継ぐ。
メディアフォルダと取り込み起点については [007 設定画面](../../007-settings-screen/spec.md) が
本書を置き換える。

## 意味が変わる既存項目

| 変数           | 変化                                                                                           |
| -------------- | ---------------------------------------------------------------------------------------------- |
| `MDM_DATA_DIR` | `mdm.db` に加えて `thumbnails/` を持つ。削除しても再スキャンで復元できる（利用者データを除く） |

## 導出される場所（設定にしない）

| 対象         | 場所                                                    |
| ------------ | ------------------------------------------------------- |
| データベース | `MDM_DATA_DIR/mdm.db`（001 から変更なし）               |
| サムネイル   | `MDM_DATA_DIR/thumbnails/<先頭2文字>/<content_key>.jpg` |

## 起動前の確認

001 の確認（`MDM_DATA_DIR` を作れること、`ffprobe` と`ffmpeg` が `PATH` にあること）に加え、
`MDM_DATA_DIR/thumbnails` を作成できることを
確認する。作成できない場合は、他の確認結果とまとめて列挙して起動を中止する。
