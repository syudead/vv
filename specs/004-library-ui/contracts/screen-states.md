# 契約: 画面の状態と操作の規則

**Feature**: [../spec.md](../spec.md) | **Plan**: [../plan.md](../plan.md)

FR-002 は「すべての画面が、通信中・成功・空・失敗の4状態に対してそれぞれ決まった見た目を
持つこと」を求めている。本書はその 4 状態を画面ごとに定め、あわせて操作（キーボード・
読み上げ・指）の規則を定める。実装はこの表を満たしていればよく、字面どおりの文言で
なくてよい（文言は表の意図を保つ限り調整してよい）。

## 1. 一覧画面 `/`

| 状態 | 条件 | 見せるもの |
| --- | --- | --- |
| 通信中 | 1 ページ目を待っている | 固定の帯は**先に**出す（探す・並べ替える・取り込むは押せる）。項目の場所には枠と同じ比率の骨組みを並べる。件数の文言は「読み込み中…」 |
| 成功 | 1 件以上 | 項目の格子。件数の文言（FR-008） |
| 空（蔵書が 0） | `total === 0` かつ検索語が空 | 動画の置き場所と「取り込む」への案内（FR-009） |
| 空（該当が 0） | `total === 0` かつ検索語がある | 検索語を示し、「検索語を消す」を置く（FR-009） |
| 失敗 | 取得に失敗した | 失敗の枠。**固定の帯は残り、操作できる**（FR-002）。再試行の入口を置く |

続きのページの読み込み中は、上の「通信中」ではなく末尾に細い知らせを出す。すでに読めて
いる項目を骨組みに置き換えない。

### 件数の文言（FR-008）

| 場面 | 文言の骨子 |
| --- | --- |
| 検索していない | 「N 本」 |
| 検索している | 「「<検索語>」に一致 N 本」 |
| 読み込み中 | 「読み込み中…」 |

利用者が「いま絞られているのか」を文言だけで判断できることが要求である。

### 固定の帯（FR-007 / R-404）

常に画面上にあり、次の 4 つを持つ。狭い画面では 2 行に折り返す（重ねない）。

1. 探す（検索欄）
2. 並べ替える（選択欄）
3. 表示の密度（選択欄。FR-017）
4. 取り込む（状態の文言 + ボタン。FR-010）

取り込みが進行中のあいだ、状態の文言は「済んだ数 / 総数」を示し、終わったら一覧を
読み直す（FR-010）。この振る舞いは既存の `ScanStatus` のままで、置き場所だけが帯の中に
変わる。

### 一覧の 1 項目（FR-005 / FR-006 / FR-011）

| 事項 | 規則 |
| --- | --- |
| 枠 | 16:9 固定。サムネイルの有無で大きさが変わらない（SC-003） |
| サムネイル未生成 | 枠の中に理由（「画像を準備中」／「画像を作れませんでした」） |
| 長さ | 枠の右下。取れていなければ出さない |
| 視聴状況 | [data-model.md 3.](../data-model.md) の読み替えに従う |
| 再生できない | 枠の左上に理由（`unplayableText` の文言） |
| 題名 | 2 行で省略。全文への到達手段は 3 つ（R-409） |

## 2. 再生画面 `/videos/:id`

| 状態 | 条件 | 見せるもの |
| --- | --- | --- |
| 通信中 | 動画の情報を待っている | 「一覧へ戻る」を**先に**出す。映像の場所には 16:9 の骨組み |
| 成功 | 情報が取れた | 映像・題名・情報欄 |
| 空 | — | この画面に「空」は無い（対象が 1 件と決まっている） |
| 失敗 | 取得に失敗した／id が不正 | 失敗の枠と「一覧へ戻る」。映像は出さない |

### 並び（FR-012〜FR-016）

上から順に固定する。

1. 一覧へ戻る（常に見えている。FR-016）
2. 題名
3. 知らせの置き場（再生できない形式の警告 FR-015、再生の失敗、続きから始まった知らせと
   「先頭から見直す」FR-014）。**映像の外**で、映像を隠さない
4. 映像（`--color-surface-sunken` の地の上、画面幅に収まり比率を保つ。FR-012）
5. 情報欄（題名・長さ・解像度・形式・映像・音声・大きさ。FR-013。取れていない項目の
   扱いは [data-model.md 3.](../data-model.md)）

3 が映像より**上**にあるのは、「映像を隠さない」ことと「見落とさせない」ことを同時に
満たすためである。映像の上に重ねると FR-014 に反し、情報欄の下に置くと気付かれない。

## 3. 操作の規則（FR-003 / FR-020 / FR-021 / FR-022）

### キーボード（FR-003 / FR-020 / SC-005）

| 事項 | 規則 |
| --- | --- |
| 到達順 | 固定の帯（探す → 並べ替える → 密度 → 取り込む）→ 一覧の項目（並んでいる順） |
| 狙いを合わせた印 | `--color-focus` の輪郭。`:focus-visible` で出す（ポインタで押しただけでは出さない） |
| 印の視認 | 輪郭は要素の外側に描き、隣の項目に隠れない |
| 一覧 → 再生 | 項目は `<a>` なので Enter で移る |
| 再生・一時停止 | ブラウザ標準の `<video controls>` に任せる（自前の操作盤を作らない） |
| 再生 → 一覧 | 「一覧へ戻る」が最初の到達先である |
| 省略の解除 | 項目に狙いを合わせると題名の全文が出る（R-409） |

**マウス操作 0 回で一覧 → 再生 → 一覧を往復できること**が SC-005 の要求である。

### 読み上げ（FR-021）

| 見た目だけの要素 | 読み上げに渡すもの |
| --- | --- |
| サムネイル | 画像は `alt=""`（題名はリンク名が持つ）。未生成のときは枠の中の文言をそのまま読ませる |
| 視聴済みの印 | 文言（「視聴済み」） |
| 途中の帯 | 「N% まで再生済み」 |
| 取り込みの進捗 | 状態の文言（帯そのものは `aria-hidden`） |
| 骨組み表示 | 領域全体に「読み込み中」を伝える（個々の骨組みは読ませない） |
| 件数の文言 | 変化を知らせる領域にする（検索の結果が変わったことが分かる） |

リンクのアクセシブル名は**常に題名の全文**である（見た目の省略に引きずられない。R-409）。

### 指（FR-022 / SC-004）

| 事項 | 規則 |
| --- | --- |
| 当たり判定 | 押せる要素は `--size-tap`（44px）四方以上 |
| 重なり | 幅 360px・768px・1280px・2560px のいずれでも操作要素が重ならない |
| 横スクロール | 上の 4 つの幅で発生しない |

一覧の項目そのものは 44px より大きいので、この規則の対象は帯の中の 4 つと再生画面の
ボタンである。

## 4. 変えないこと（FR-025 / SC-009）

本書は**見せ方**だけを定める。次は 002 のまま変わらない。

- 1 ページ 60 件の無限スクロール、カーソルの引き継ぎ
- 検索の待ち合わせ（250ms）と打ち切り
- 再生位置の送信（5 秒ごと、離脱時の `sendBeacon`）
- 続きから始める下限（5 秒）と視聴済みの判定（サーバー側）
- 取り込みの巡回（2 秒ごと、実行中だけ）
