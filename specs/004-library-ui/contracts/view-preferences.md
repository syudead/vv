# 契約: 表示設定の保存

**Feature**: [../spec.md](../spec.md) | **Plan**: [../plan.md](../plan.md) |
**Research**: [R-407](../research.md) | **Model**: [../data-model.md](../data-model.md)

本機能が**唯一新しく永続化するもの**の取り決めである。保存先は利用者の端末の
`localStorage` で、サーバーは関与しない（FR-018・FR-024）。

## 1. 鍵と値

| 事項 | 値 |
| --- | --- |
| 保存先 | `window.localStorage` |
| 鍵 | `vv.view.v1` |
| 値 | JSON のオブジェクト 1 個 |

```json
{ "density": "standard", "sort": "addedDesc" }
```

| 項目 | 取りうる値 | 既定値 |
| --- | --- | --- |
| `density` | `"dense"` / `"standard"` / `"relaxed"` | `"standard"` |
| `sort` | `api/openapi.yaml` の `VideoSort`（現在 `"addedDesc"` / `"titleAsc"`） | `"addedDesc"` |

未知の項目が入っていても無視して読み進める（他の版が書いた値を壊さない）。書き込みは
上の 2 項目だけを書き、読んだときに残っていた未知の項目は**引き継がない**（引き継ぐと、
壊れた値を永久に運び続けることになる）。

## 2. 公開する関数

`web/src/preferences/viewPreferences.ts` が次の 2 つだけを出す。画面はこの 2 つ以外から
`localStorage` に触らない。

| 関数 | 署名 | 約束 |
| --- | --- | --- |
| `readViewPreferences` | `(storage?: Storage) => ViewPreferences` | **決して投げない。** 必ず完全な値を返す |
| `writeViewPreferences` | `(value: ViewPreferences, storage?: Storage) => void` | **決して投げない。** 失敗は黙って捨てる |

`storage` を引数で受けるのは、単体テストが偽の実装（投げる・満杯・壊れた値を返す）を
渡せるようにするためである。省略時は `window.localStorage` を使い、それ自体の参照が
投げる環境（プライベートウィンドウ）も想定する。

## 3. 読み出しの規則（FR-019）

上から順に判定し、当たった時点で確定する。**どの段でも例外を外に出さない。**

| # | 状況 | 結果 |
| --- | --- | --- |
| 1 | `localStorage` を参照できない／`getItem` が投げる | 既定値すべて |
| 2 | 鍵が無い（`null`） | 既定値すべて |
| 3 | `JSON.parse` が投げる | 既定値すべて |
| 4 | 値がオブジェクトでない（`null`・配列・数値・文字列） | 既定値すべて |
| 5 | `density` が想定外 | `density` だけ既定値 |
| 6 | `sort` が想定外 | `sort` だけ既定値 |
| 7 | どちらも正しい | そのまま使う |

5 と 6 が**項目ごと**であることが重要である。片方が壊れただけで利用者の選択を丸ごと
捨てない。

## 4. 書き込みの規則

| 場面 | 書く項目 |
| --- | --- |
| 密度を変えた | `density`（`sort` は現在値のまま） |
| 並び順を変えた | `sort`（`density` は現在値のまま） |
| 検索語を変えた | **書かない**（検索語は保存しない。次に開いたとき前回の検索で絞られていると、動画が消えたように見える） |

書き込みが失敗しても、画面上の設定はその場では効いたままにする。「保存できませんでした」
という知らせは出さない（利用者に取れる対処が無く、FR-002 が求める失敗の表示は**取得と
表示の失敗**についてのものである）。

## 5. 版を上げるとき

項目の意味や取りうる値を変えるときは、**鍵の版を上げる**（`vv.view.v2`）。

- 古い鍵は読まない。移行コードを書かない。
- 古い鍵を消す処理も書かない（消せなくても害が無い）。
- 利用者の設定は既定値に戻る。これは FR-019 が正常と定めている状態である。

## 6. この契約の検査

| 事項 | 検査 |
| --- | --- |
| 3. の 7 つの場合すべてで完全な値が返り、投げない | 単体テスト（偽の `Storage` を渡す） |
| 書き込みの失敗を握りつぶす | 単体テスト（`setItem` が投げる `Storage`） |
| 端末をまたがない | 受け入れ検証 [S6](../quickstart.md)（別のブラウザで開く） |
| 再読み込み・画面遷移で保たれる | 受け入れ検証 [S6](../quickstart.md)（SC-007） |
