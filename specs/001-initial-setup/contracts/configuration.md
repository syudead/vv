# 設定の契約（Phase 0）

**Feature**: [spec.md](../spec.md) | **Plan**: [plan.md](../plan.md) | 対応する要件: FR-004

設定は環境変数のみで与える。設定ファイルは持たない（[R-004](../research.md)）。
すべて未設定でも起動できる。

## 環境変数

| 変数 | 既定値 | 意味 | 不正時の扱い |
| --- | --- | --- | --- |
| `MDM_ADDR` | `:8080` | 待ち受けアドレス | 解釈できなければ起動中止 |
| `MDM_MEDIA_DIR` | `/media` | 動画ファイルを探す場所（Phase 0 では読み取り可否の確認のみ） | 絶対パスでない／読めない場合は起動中止 |
| `MDM_DATA_DIR` | `/data` | データベースなど、アプリケーションが書き込む場所 | 絶対パスでない／作成できない場合は起動中止 |
| `MDM_LOG_LEVEL` | `info` | 記録の詳細度（`debug` / `info` / `warn` / `error`） | 未知の値は起動中止 |

- データベースのパスは `${MDM_DATA_DIR}/mdm.db` に固定し、設定項目にしない。
- 検証は起動時に**まとめて**行い、不正な項目を一度に列挙して終了する。
- 秘密情報は現時点で存在しない。Phase 3 で認証を入れる際に、
  値そのものを記録へ出さない規則をここへ追記する。

## 起動前の前提確認（FR-008）

設定の検証に続けて、外部コマンドの存在を確認する。

| 対象 | 確認方法 | 欠けていた場合 |
| --- | --- | --- |
| `ffprobe` | 実行パスの探索 | 不足しているコマンド名と導入方法を出力し、終了コード非0で停止 |
| `ffmpeg` | 実行パスの探索 | 同上 |

出力例（文言は実装時に固定する）:

```text
起動前の確認に失敗しました。
  - ffprobe が見つかりません。コンテナで実行するか、ffmpeg を導入してください（alpine: apk add ffmpeg）。
  - MDM_MEDIA_DIR=/media を読み取れません（no such file or directory）。
```

Phase 0 の機能はこれらのコマンドを使わないが、Phase 1 で必須になるため、
「起動できた＝前提が揃っている」状態をここで保証する。

## 記録（ログ）

`log/slog` の JSON ハンドラで標準出力へ出す。起動時に、有効な設定値
（`MDM_ADDR`・`MDM_MEDIA_DIR`・`MDM_DATA_DIR`・`MDM_LOG_LEVEL`）と
バージョン情報を1行で記録する。これにより「どの設定で動いているか」を
後から追跡できる（FR-007）。
